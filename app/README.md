# LCSC3D 2.4.2 使用说明

## 商城选型与采购

商城页签依次为 **搜索商品 / 我的收藏 / 购物车 / 我的订单**，四页均为原生界面。数据手册兼容商城新版资料列表、厂商外链和旧版 PDF 字段；商城未提供手册时补用元件目录链接。

1. **直接填写数量**：搜索和收藏提供“数量”输入列，输入本次增加的数量后右键 **添加到购物车** 即可，保持当前页面。已知起订量作为初始值，按器件递增量加减；手动输入向上取整为有效数量。搜索和收藏表格显示“递增量”，数量在翻页和切换列表时保留，同一器件在这些列表中同步。购物车已有数量会累加。收藏中缺少购买规则时显示“—”，加购前仅查询所选器件的规则；原数量不足时更新表格并提示确认，不会直接按增加后的数量加购。
2. **右键快捷操作**：器件行提供 **添加到下载列表 / 添加到收藏 / 添加到购物车**。右键已勾选行作用于当前勾选集合（搜索含跨页勾选），右键未勾选行只操作该行；批量加购按各行数量提交。单个器件明确被商城拒绝时继续其余器件；成功项自动取消加购勾选，避免重试时重复增加。
3. **原生购物车**：读取账号购物车，显示商品预览图、器件、型号、封装、单价、递增量、数量、小计和状态。图片按可见行后台加载并缓存，双击图片可放大。数量按递增量在行内修改并自动保存；支持勾选、移除和导入下载列表。保存失败后需刷新核对。
4. **跳转到购物车**：直接用系统默认外部浏览器打开立创商城购物车。按钮不提交结算、不修改网页的勾选状态；在网页确认商品后点击“结算”，继续填写和确认订单。软件数量修改会自动保存，请在保存完成后刷新网页核对；浏览器请使用同一商城账号。
5. **原生我的订单**：分页显示订单号、时间、商品、金额、订单状态和付款状态，支持关键词与状态筛选。点击订单行，在原来的订单表格区域查看购买的器件、物品、预览图、数量、单价、金额和订单合计；勾选器件后可加入下载列表。点击“返回订单列表”保留筛选、页码、选中行和滚动位置。“查看订单详情”位于明细页内，用外部浏览器查看商城完整订单。非器件物品照常显示，无法识别器件编号的项目不导入下载列表。

**分类与筛选**：搜索页底部的“分类”和“筛选”在原搜索结果区域打开原生页面。分类取自商城电子元器件分类，可搜索分类名称、双击进入。筛选支持官方当前范围内的类目、品牌、封装、包装、标签、认证、器件参数、多选与数值范围，以及现货、折扣、数据手册、国产/国际品牌、排序、价格、需求数量和结果内搜索；候选项随条件更新，应用后分页仍保留条件。点击“返回商品”保留原列表与勾选；提交新的关键词开始新搜索。

**表格操作**：列头显示分隔线，可拖动调整宽度，双击分隔线适应内容。下载列表仅保留下载选择、器件编号、型号/模型和结果。订单、收藏和购物车图片只补查可见行，双击订单图片可查看原图。

**数值范围**：例如在 MCU 的“程序存储容量”中输入最小值 `32`、最大值 `64`，单位选 `KB`，点击“选用范围”后显示范围内选项；数值和单位在更新选项及切换分组后保留。点击“应用筛选”查看匹配商品；也可以直接填写有效范围后点击“应用筛选”。“清除此项”同时清除所选范围与该参数的离散选项。

搜索、加购、购物车与订单通过后台请求处理，不创建商城网页组件或独立的数量选择页面。退出账号清空购物车和订单表格；程序自有配置和诊断仍在 LOCALAPPDATA 下，不写到 EXE 旁。日志只记录操作阶段、数量、结果和错误类型，不记录订单编号、订单正文、收货资料或登录凭据。停售商品显示“已停售”并说明原因。加购通知区分成功、失败、未确认与未发送，点击“查看结果”可在消息页看到逐项数量与原因。网络故障导致结果未确认时停止后续加购；请先核对购物车再重试，避免重复增加。

以上采购功能适用于中文模式的立创商城账号；英文模式通过 LCSC.com 管理国际站账号。

新导出的 AD SchLib 默认开启元件位号和 Comment 显示，两者分行放在符号上方，适用于嘉立创风格、AD 原生风格、独立库、合并库和追加的新元件。旧库中的既有元件不会被批量改写；需要更新的元件请重新导出。KiCad 符号的 Reference 和 Value 也默认显示，已对实际输出核验。

Windows 10/11 x64 便携软件，用嘉立创商城 C 编号下载官方 STEP/OBJ 模型、导出原生 AD 或 KiCad 符号与封装库，提供模型、符号、封装和商品图片预览与自更新。运行文件固定为 `LCSC3D.exe`，源码包为 `LCSC3D.zip`，版本号单独显示。

3D 预览读取官方 OBJ 网格，STEP 可独立下载。当前模型关联没有可用 STEP 时，程序会查询封装所关联的官方 3D 库，解析真实资源编号后尝试备用 STEP。单独下载的模型保留官方原始坐标和内容；关联到封装时，保留原始 STEP 的尺寸和内容，先按官方规则换算 XY 中心和最低 Z 基准，再应用 JSON 位置与角度。基准来自实际 STEP 资源配套 OBJ 的顶点扫描；不构建网格，不读取 STEP 几何，不进行表面比对或缩放。

2.4.0 默认开启 **封装关联 3D 模型**，支持 AD 内嵌 STEP、KiCad 9/10 内嵌模型和 KiCad 8 外部模型兼容模式。已有设置自动补充默认值。Windows 正式程序、源码包和校验文件在 GitHub 的 v2.4.0 Release 中提供。

## 下载进度与消息

进度条在查询元件、准备模型、处理导出格式、合并及写库阶段持续更新，以约 320 毫秒缓动到达新进度。百分比表示处理阶段的综合进度，不等同于下载字节比例；等待当前网络请求时不会自行跑到完成。普通导出、AD 合并/追加与 KiCad 都参与统计，写入结束后才达到 100%，停止任务保留实际进度。

左侧“立创商城”下方的“消息”可查看已经弹出的通知，按时间倒序排列，支持搜索、类型筛选、完整内容查看、复制与清空记录。下载完成/停止、模型提醒、更新检查和失败、日志打包/清除等结果统一在主窗口右上角显示；新通知在上，较早的通知平滑下移。最多同时显示三条，窗口较小时更早的通知收起，但历史记录保留。

历史保存至 `%LOCALAPPDATA%\LCSC3D\messages\history.json`，重启可查看，最多 500 条且不超过 1 MiB；只记录通知的时间、类型、标题、内容和详情，不保存可执行按钮。已消失的确认通知需回到对应功能重新发起。消息内容不自动加入诊断 ZIP；清除日志和清空消息分别处理。消息文件写入失败时，本次运行仍可查看并显示保存失败提示。

本版验证见 [2.4.1 验证记录](../docs/2.4.1验证记录.md)，既有模型与消息功能见 [2.4.0 验证记录](../docs/2.4.0验证记录.md)，源码目录见 [代码结构](../docs/代码结构.md)。

## 封装关联 3D 模型

模型放置修复：2.4.0-demo.4 省略了必要的模型放置基准换算，造成 Type-C 等模型水平和高度偏移。本版恢复该换算，继续保留 STEP 原始尺寸和字节；关联时获取配套 OBJ，仅扫描顶点极值。普通批量导出刷新源数据，暂未启用基准缓存复用。没有 CAD 工作进程、网格化或几何比对。模型宽高不参与缩放计算，缺少宽高也不阻止关联。此前版本已经生成的库需要普通导出或重新合并，追加模式不会自动改写旧条目。

保留此前原点修复：C2861386、C57113、C83790 的 JSON 存在旧模型原点。软件现在复现标准版把封装放入 PCB 时按模型外框更新原点的步骤，消除错误偏移与告警。此前导出的受影响库需要用普通导出或重新合并生成；追加模式保留旧条目，不能自动修复旧模型位置。模型角度和高度继续保留官方值，尺寸采用 STEP 原始物理尺寸。

勾选 PcbLib 或 KiCad 封装库后，保持 **封装关联 3D 模型** 开启即可。无需另勾 STEP；关闭此开关只导出二维封装。关联选项与 KiCad 模型兼容模式会随设置保存。

- **Altium Designer**：模型内嵌到 `.PcbLib`，覆盖单器件、合并、保留副本和追加已有库。内嵌 STEP 解压后的内容与下载的原文件一致。
- **KiCad 9/10 · 内嵌模型**：默认模式，模型包含在 `.kicad_mod` 中，移动封装文件时随之移动。
- **KiCad 8 · 外部模型**：STEP 放在 `.pretty/LCSC3D.3dshapes/` 内，通过库内相对路径引用。添加封装库时昵称须与导出库名一致；移动时保留整个 `.pretty`，并更新 KiCad 封装库表中的路径。
- **没有关联模型**：二维导出成功，结果注明“无关联 3D 模型”。
- **无法可靠放置**：参数缺失或无效、资源不可用、STEP 文件头尾不完整或放置超出目标格式范围时，跳过受影响模型并显示“部分完成”；其他模型和二维封装保留。
- **按来源基准解释位姿**：保留官方偏移、角度和负高度，先减去模型基准再旋转平移。无法获取基准时跳过该模型并提醒，不默认为零偏移。
- **AD 的二维 Body 外框**：使用封装焊盘范围作为显示占位，不代表模型实际外形或高度，也不用于修改模型位置。真实三维形体由内嵌 STEP 提供。

一批任务完成后，右上角滑动弹窗汇总需核对的元件，支持 **复制元件编号** 和 **复制详情**。逐元件结果保留具体原因。相同二维封装只有在模型内容和放置也相同的情况下才复用。

当前使用 **嘉立创EDA标准版** 的位置、角度与原点更新规则，信任官方模型资源关联。配套 STEP/OBJ 坐标基准一致是轻量放置的前提；二者的几何差异不进行全量检测，额外设置的模型缩放不复现；软件预览仍显示官方 OBJ，导出的 STEP 可能与它不同。程序不解释 STEP 内部几何，完整实体可读性由 AD/KiCad 处理；旧版边界缓存不再读取或写入。实现边界见 [3D 模型放置](../docs/3D模型放置.md)。

2.3.0 新增 KiCad 8+ 符号与封装导出，以及版本化的 EDA 中间层。通过“导出到”选择 AD 或 KiCad，可独立导出或分别合并符号库与封装库，配置库名并保留单器件副本。KiCad 引脚电气类型可跟随源数据或统一设置，不支持的值使用“未指定”；符号预览固定为 KiCad 风格，矩形使用直角与实心主体背景填充。

本版修正部分符号的引脚方向，支持 C31966 等封装中的 VIA 过孔，并修复长结果文字重叠、控制栏间距与合并开关闪动。AD 保留原生过孔；KiCad 封装以无编号镀通孔保留孔和铜环，网络归属需在 PCB 中确认。日志覆盖 AD/KiCad 转换、替换、回滚和逐格式结果；诊断包不包含原始器件 JSON 或登录凭据。

## KiCad 导出（第一版）

工作台底部使用 **导出到 → Altium Designer / KiCad** 选择软件，只显示对应配置。STEP、OBJ 是两种目标均可选择的模型格式。切换目标保留各自配置，隐藏的格式和 AD 追加选项不参与本次导出。设置会保存并在重启后恢复，导出期间锁定选择。

- **独立导出**：不启用合并时，按器件放入独立文件夹，例如 `LCSC3D_C20197.kicad_sym` 与 `LCSC3D_C20197.pretty/封装名称.kicad_mod`。
- **Lib → 合并**：与 AD 一样，勾选后显示符号和封装的两行配置，分别选择是否合并、填写库名、勾选“独立导出器件”。KiCad 没有“追加”模式。
- **合并符号库**：在保存目录生成一份 `符号库名.kicad_sym`。不要求同时合并封装。
- **合并封装库**：在保存目录生成一个 `封装库名.pretty`，收纳本批次 `.kicad_mod`。相同封装复用，同名但不同内容自动区分。可以只导出合并封装，也可以搭配独立符号库；符号的 Footprint 字段始终引用实际导出的封装库昵称和条目。
- **独立导出器件**：分别为已合并的符号或封装额外保留单器件库，库名为“对应合并库名_C编号”。未保留独立器件时，模型集中到“符号库名_3D”；只合并封装时跟随封装库名。任一合并项保留独立器件时，模型放入各器件文件夹，与 AD 一致。
- **引脚电气类型**：默认“跟随源数据”，按中间层逐引脚映射。支持输入、输出、双向、三态、无源、自由、电源输入、电源输出、开集电极、开射极、不连接和未指定。选择具体类型会统一覆盖本次所有符号引脚；未知类型或未明确方向的源“电源”类型回退为“未指定”，不修改中间层记录。
- **库名**：符号和封装默认都为 `LCSC3D`，可以分别修改；封装库名同时作为封装库昵称。只能填名称，不能包含路径、冒号或 Windows 禁用字符；允许填写对应扩展名。
- **再次合并**：AD 和 KiCad 普通导出、合并导出均覆盖同名库，以本次成功转换的选择为准。例如先合并 A、B，再改为 A、C，结果为 A、C，B 不再保留。KiCad 同名 `.pretty` 目录整体更新并移除旧成员；其他名称的库不受影响。写入失败或取消时恢复原 KiCad 库。AD 的“追加”模式继续保留原库成员。

在 KiCad 中使用导出结果：

1. 打开“首选项 → 管理符号库”，选择项目或全局范围，添加导出的 `.kicad_sym`。
2. 打开“首选项 → 管理封装库”，添加对应的 `.pretty` 文件夹；**昵称须与导出库名完全一致**。独立库示例为 `LCSC3D_C20197`，合并库示例为 `LCSC3D`。
3. 放置符号，核对其 Footprint 字段，再从原理图更新 PCB。只导出符号时 Footprint 字段留空，后续可在 KiCad 中自行关联封装。

文件面向 KiCad 8+，验证 KiCad 8.0.9、9.0.9 和 10.0.7。保留多单元、引脚编号和名称、重复焊盘编号、铜孔偏移、槽孔方向、镀孔与定位孔。符号使用 KiCad 原生字体和配色，名称与编号字号最高 1.27 mm；矩形统一使用直角、实心填充，采用“主体背景颜色”。来源圆角仍保留在中间层，KiCad 导出和预览不使用圆角；焊盘形状不受此规则影响。

椭圆及无法直接表达的曲线按 0.00127 mm 公差离散。器件外形投影层按装配轮廓显示，结果文字与日志会提示这些转换。未知图层或无法准确表达的关键图元会报告对应格式失败，其他有效格式可以继续完成。

暂不自动注册 KiCad 工程库、不追加已有 KiCad 库。模型关联与 STEP/OBJ 独立下载分别控制。选择 KiCad 时，符号预览固定为 KiCad 风格：深红轮廓与引脚、青色名称、红色编号、浅黄不透明矩形；隐藏嘉立创/AD 风格选择。预览在官方 SVG 上应用样式，并非 KiCad 原生文件渲染，字体排版可能不同。切回 AD 恢复此前风格选择；封装预览仍为官方资源。

架构和后续 EDA 扩展规则见 [EDA 中间层](../docs/EDA中间层.md)。

2.3.0-demo.3 修复 C5879483 等来源引脚路径反向时的连接端识别，同时修复 AD/KiCad 实际导出和预览。此前受影响的库需要重新导出。下载结果长文字会按实际换行高度排版，上方列表与底部导出设置保持间距；窗口较小或字号较大时可滚动查看。

## 符号风格切换

导出目标为 **Altium Designer** 时，器件预览的 **符号** 页提供 **符号风格：嘉立创 / AD**，其他预览页隐藏此项。所选风格同时作用于符号预览和新导出的 SchLib，切换预览页仍保留选择。样式切换使用已加载的数据，无须重新下载；多单元选择、缩放和平移继续可用。

- **嘉立创风格**：默认选项，保留官方符号原有配色、字体和线条。
- **AD 风格**：使用深红轮廓、黑色引脚、深蓝 Times New Roman 文字。引脚名称、编号及普通文字分别保留原字号，只统一字体和颜色；SchLib 继续按其字体表的整数点数字号导出。矩形统一为原生直角 Rectangle，Border 使用 **Small**；填充按参考库使用浅黄 Fill Color，同时勾选 Fill Color 和 Transparent，无论原图元是否填充。预览以半透明填充表达 Transparent，画布背景保持白色。
- **引脚长度**：AD 风格的最小长度为 **200 mil**。较短引脚向外延长，本体端位置保持不动；200 mil 及以上保持原长。预览同步移动外部连接点与引脚编号，原引脚名称的位置保持不动。嘉立创风格保留原长度及圆角。
- **电气类型**：两种风格导出的所有引脚均为 Passive（被动），保留编号、名称、方向、可见性、单元归属和封装关联。
- 选择立即保存到应用数据目录，重启恢复；下载期间锁定风格，确保该批次的导出样式一致。适用于独立、合并和追加导出，追加时已有库条目保持原样，只有新加入的符号采用所选风格。

样式规则在预览与导出之间共用；APP 预览采用官方 SVG，AD 使用原生 SchLib 图元，两者的字体排版由各自渲染器处理。封装及 3D 模型继续使用原始资源。

程序内部文件统一存放在 `%LOCALAPPDATA%/LCSC3D/`：配置和加密会话位于根目录，日志位于 `logs/`，诊断 ZIP 位于 `diagnostics/`，缓存位于 `cache/`，临时文件位于 `temp/`，单文件 EXE 的运行时解压位于 `runtime/`，更新下载、计划和备份位于 `updates/`。正常启动和关闭不在 EXE 目录生成配置或日志。模型和元件库默认保存到 `downloads/`，也可主动选择其他导出目录。

- **检查更新**：控制新版检查、校验文件和更新包下载。

选择 **使用系统代理** 时，优先读取 HTTP/HTTPS 环境变量代理，没有环境变量代理时读取 Windows 当前用户的手动系统代理，并遵守代理绕过规则。选择 **不使用系统代理** 时，忽略系统和环境变量代理。两项对保存后的新请求立即生效，不清除当前登录会话；已经发出的请求继续完成。此选项不控制浏览器打开的网页，也不关闭 VPN/TUN 等网络层转发。

**设置 → 日志与诊断** 可选择 **Debug / Info / Warning / Error / Critical**，默认 **Debug**。所选等级及更严重的信息会写入日志，保存后立即生效，启动阶段也遵守已保存的等级。点击 **打开日志** 打开 `%LOCALAPPDATA%/LCSC3D/logs`。主程序写入 `LCSC3D.log`，独立更新助手写入 `LCSC3D-update.log`，各自单个文件最多约 2 MiB，保留最近 3 份轮转备份。

**打包日志** 在后台生成 ZIP，包含主程序、更新助手、轮转、崩溃日志及运行状态标记，另附 `diagnostics.json`（软件/系统/Python/Qt 版本、当前生效的代理模式、日志等级、主题、按钮文字颜色、界面字体、日志写入状态及收集清单）和反馈说明。ZIP 保存在 `%LOCALAPPDATA%/LCSC3D/diagnostics/`，完成后打开该目录。它不读取会话文件、完整配置、代理地址、环境变量或模型；异常大文件保留最近内容，读取失败或截短会在界面和收集清单中说明。

**清除日志** 会先在右上角通知中确认，清除当前和历史日志后继续记录。设置、登录状态、下载文件、运行状态标记和已打包的 ZIP 保留。其他进程正在使用或无权限的文件可能无法清除，界面会显示未清除数量。

日志覆盖启动/退出、设置保存和迁移、输入与下载队列、型号查询、商城搜索/资料/图片/收藏、三种登录与图片验证、会话保存/恢复/清除、逐元件逐格式下载、SchLib/PcbLib 转换与文件写入、3D/SVG 预览，以及检查更新、校验、替换、重启和回滚。记录操作结果、阶段、元件编号、格式、请求耗时、状态码、系统错误码和异常原因链，并包含文件/函数/行号。

每条日志包含进程、线程和运行会话编号。`root_id` 关联同一次操作，`operation_id` / `parent_id` 关联子步骤，`error_id` 标识异常；后台线程和自更新助手继续保留关联关系。`*.finished` 表示步骤返回，具体是否成功以 `*_result` 的状态或 `*.failed` 为准。取消和图片验证要求单独记录。

日志不记录账号密码、Cookie、短信验证码、授权链接、完整请求地址、响应正文、异常原文或局部变量。预览记录固定错误分类及 WebGL 环境；未捕获 Python/线程异常统一记录。可捕获的本机崩溃会额外生成 `LCSC3D-crash-进程号.log`，其中为线程代码栈，可能包含运行时文件路径，不包含局部变量；正常退出会移除空文件，保留最近 3 份已结束进程的历史崩溃文件。非正常退出标记会在后续启动时检查。

排查问题时保持 **Debug**，复现后点击 **打包日志**，发送 ZIP 并附上发生时间、操作步骤和完整报错截图；下载或预览问题请提供元件 C 编号和格式。完整步骤被记录后，可以追到发生问题的功能、阶段及代码位置；断电、系统强制终止或日志目录不可写可能导致记录缺失，不能保证仅凭日志确认所有外部故障的最终根因。详见 [日志覆盖与排查](../docs/日志排查.md)。

## 备份与恢复

**设置 → 备份** 管理已有 `.SchLib`、`.PcbLib` 和 `.PrjPcb` 文件在追加或工程导入前的备份，统一保存在 `%LOCALAPPDATA%/LCSC3D/backups/`。不包含登录会话、日志或自更新的 EXE 回滚副本。

- **自动备份** 默认开启，切换后点击设置底部的 **保存** 生效；取消或返回不应用开关。关闭后，修改已有库或工程时不再新增自动备份，已有备份仍可恢复。
- 列表显示备份时间、文件、原位置与文件大小，上方显示备份总数和磁盘占用（包含元信息）。进入备份页或点击 **刷新** 更新；**打开目录** 打开备份存放目录。
- 选择一行后点击 **恢复选中备份**。新备份默认填入原位置，也可输入新的完整路径或选择已有文件；目标扩展名必须与备份一致。旧版备份未记录原路径，需要手动指定目标。
- 点击 **恢复备份** 后先校验文件，再显示目标路径供确认；**确认恢复** 后才写入。如果目标已存在，会先保留当前内容，即使自动备份开关关闭也执行此保护，可以再恢复该副本撤回操作。备份损坏、目标在确认后发生变化或写入失败时不会静默覆盖。
- **清除备份** 显示当前数量和占用空间，确认后删除这些备份；取消不删除。原库、工程以及确认后新产生的备份保留，清除后可以继续自动备份。被占用的文件会报告失败，可处理后重试。

恢复和清理在后台执行；导出任务运行时不可执行恢复或清理，备份操作完成后才能开始新的导出。单个备份支持最大 512 MiB；恢复新格式前验证 SHA-256，旧版副本先检查 AD 库或工程格式。

## 登录、记住登录与账号收藏

本节介绍简体中文模式的国内商城。English 模式的国际站账号操作见上方“国际站账号”。

1. 点击应用右上角 **账号登录**；所有页面共享此入口和登录状态。
2. 在原生登录框选择 **扫码登录 / 账号密码 / 手机验证码**。扫码用微信确认；账号密码直接在软件内输入；短信登录先获取验证码再提交。若商城要求图片验证，在同一登录框输入图中文字，支持 **换一张**。短信发送后有 60 秒重试倒计时。
3. **记住登录，下次启动自动恢复** 默认勾选。重启软件自动恢复并校验会话，无须重新登录；取消勾选则只在本次运行中保留登录。会话过期后需重新登录。
4. 打开 **立创商城 → 账号收藏**，已登录时自动获取收藏；也可点击 **获取收藏** 刷新。软件后台读取全部账号收藏，筛选框用于过滤已获取元件。
5. 收藏元件默认不勾选，勾选需要的元件并点击 **加入下载列表**，随后在主窗口选择格式并开始下载。收藏的导入、全选和反选只处理当前筛选中可见的元件。选中商品可单独取消账号收藏。

收藏表格在勾选框和 C 编号之间显示商品缩略图，双击查看原图；行高、图片尺寸和滚动方式与搜索页一致。图片分批异步加载，并复用搜索页缓存；无图或加载失败显示占位，选中商品后取得的补充图片也会更新到该行。刷新、退出账号或取消收藏时，旧图片响应不会覆盖其他商品。

在商城点击“加入下载列表”后会从右上角滑入通知，显示新增、跳过已有元件的数量；输入无效或导入失败时在通知内说明原因。

导入按 C 编号去重，已有元件的勾选状态、下载结果与当前预览行保留；新元件默认勾选。尚未载入的有效手动输入也会合并；输入框有无效内容时先修正再导入。下载期间不能修改队列，可等下载结束后导入。

记住登录使用 Windows 当前用户的 DPAPI 加密，文件位于 `%LOCALAPPDATA%/LCSC3D/store-session.bin`，不保存账号密码。它只供本机当前 Windows 用户恢复会话，不包含在源码包、交付目录或日志中。切换离开商城页保留登录；**退出登录** 清除本程序当前会话、加密保存的登录状态和暂存的收藏，保留已导入的下载列表。

收藏后台获取可随时停止，停止或普通网络失败保留已获取的部分；账号登录失效会清除暂存的账号数据并提示重新登录。账号收藏的添加、取消均在服务器确认后更新列表，失败时保留现有数据。收藏读取最多 200 页、暂存 10,000 个有效 C 编号元件。商品搜索按需获取当前 20 个元件，不预取后续软件页。

登录网络错误会标明失败步骤，并区分响应不完整、超时、域名解析、证书校验和代理配置等问题。请求诊断统一写入上述日志，可在 **设置 → 日志与诊断 → 打开日志** 中查看。

本地回归覆盖代理切换、配置保存、日志等级及脱敏、登录网络失败，以及价格精度、库存、最低起订量、独立梯度选择、完整文字与参数、删除勾选器件、分页、收藏和预览。手机验证码和图片验证已在 2.1.0 开发期间经过真实账号验证；本版登录流程使用本地模拟服务回归。详见 [2.2.0 更新记录](../docs/releases/v2.2.0.md) 与 [2.2.1 更新记录](../docs/releases/v2.2.1.md)。

## 获取资源

下载列表的 **删除已勾选器件** 移除所有打勾的器件，同时更新输入框，保留未勾选器件的结果和已下载文件。若正在预览的器件被删除，会切换到剩余器件；列表清空时恢复预览占位。下载进行期间删除按钮不可用，任务结束后恢复。

1. 输入 C 编号，支持换行、空格、中英文逗号、分号；不区分大小写，重复编号自动合并。
2. 点击“载入列表”。后台查询全部器件型号，包括未勾选的器件；单击器件行切换右侧预览。
3. 在下载列勾选需要的器件，可使用“全选”“反选”。重新载入时按编号保留选择。
4. 选择保存目录与格式：3D 模型“STEP”“OBJ”，AD 元件库“SchLib”“PcbLib”。默认只选 STEP，可任意组合，也可只导出 AD 库。
5. 点击“开始下载”。任务仅处理勾选的器件，期间仍可操作预览；“停止”保留已完成文件。

文件与目录选择页使用 Material 分区：左侧为“常用位置”，右侧为文件列表，中间分隔线可拖动调整宽度。顶部提供后退、前进、上一级目录、列表视图和详细信息视图；图标随浅色/深色主题及字号更新。选择目录时隐藏无关的文件类型选项，选择已有库或工程时保留对应扩展名筛选。

下载目录保存所选的 STEP、OBJ、SchLib、PcbLib。STEP/OBJ 保持官方内容，AD 库从官方结构数据生成。已取消 JSON 和 SVG 文件导出，包括 model-info.json；不转换为 KiCad，不生成 WRL 或 CSV。

每个器件使用独立的“器件名_编号”目录，文件夹命名规则保持不变。AD 库文件仅使用元件型号命名，不附加 C 编号；STEP/OBJ 文件名保持原规则。文件名与目录名中的 Windows 禁用字符替换为下划线，缺少型号时使用“未命名器件”。例如：

```text
所选目录/
  RP2040_C2040/
    C2040_LQFN-56_L7.0-W7.0-P0.4-EP.step
    C2040_LQFN-56_L7.0-W7.0-P0.4-EP.obj
  TYPE-C 16PIN 2MD(073)_C2765186/
    TYPE-C 16PIN 2MD(073).SchLib
    TYPE-C 16PIN 2MD(073).PcbLib
```

每次下载固定重新获取所选资源并覆盖已有同名文件，界面不再提供“覆盖已有文件”选项。文件下载或生成成功后才替换，失败或取消时保留原文件；未选中的器件及格式不受影响。缺少 3D 模型时显示“无模型”，仍可预览可用的符号和封装。某种模型格式不可用时保留其他已完成格式并显示“部分完成”。停止会在当前网络读取结束后响应，读取超时 18 秒。已有文件不会因取消某种导出而自动删除。

批量下载没有 29 个器件的数量上限。服务器提示请求过于频繁（HTTP 429），或通过 HTTP 503 要求等待时，程序按服务器给出的时间等待后自动重试；未提供有效等待时间时逐步延长间隔，最多重试 4 次。同一站点的型号查询、模型和预览请求共用等待时间，等待期间点击“停止”可立即取消。服务器要求等待超过 2 分钟或持续拒绝请求时显示失败原因，可稍后重新下载；已完成文件保留。

## 合并 AD 元件库

在 AD 元件库后方的 **Lib** 区域勾选 **合并**，才会展开合并配置；**合并** 与 **追加** 互斥，也可均不勾选以按器件普通导出。选择 SchLib 或 PcbLib 格式后，可分别启用 **合并 .SchLib**、**合并 .PcbLib** 并输入名称。名称默认 `LCSC3D`；支持中文，可省略扩展名或填写对应扩展名。文件名不能包含路径、Windows 禁用字符或保留设备名，最多 115 个 UTF-16 单元。隐藏模式中保存的目标和开关不会参与当前导出。

点击“开始下载”后，本次勾选的器件按对应格式汇入同一个原生库，例如保存目录根部的 `项目符号.SchLib` 和 `项目封装.PcbLib`。每种合并格式旁的 **独立导出器件** 控制是否额外保留该格式的逐器件库，默认关闭；独立库的符号和封装保持配套引用。未合并的 AD 格式仍按器件独立导出。配置自动保存，下载期间不能修改。

参与合并的格式均未勾选 **独立导出器件** 时，所有 STEP/OBJ 集中到 SchLib 旁的 **“库名_3D”** 文件夹；仅合并 PcbLib 时，使用 **“PcbLib 名称_3D”**。库本身保留原位置。任一参与合并的格式勾选独立导出时，3D 文件按器件保存。旧的导出文件夹保留，新导出使用 `_3D` 后缀。示例：

```text
保存目录/
  项目符号.SchLib
  项目封装.PcbLib
  项目符号_3D/
    C2040_模型名.step
    C20197_模型名.step
```

独立 `.SchLib`、`.PcbLib` 文件按器件型号命名，器件编号只保留在其 **“型号_C编号”** 文件夹中；新导出的库内符号和封装名称不再自动追加 C 编号。封装名称超长时截短以适配原生库的存储限制。同名但不同内容的封装、合并时重名的符号使用 `_2`、`_3` 等序号区分。

合并和追加 PcbLib 时，比较封装图元、焊盘编号/尺寸/孔/层/阻焊信息、文字、高度与附加数据，排除随机焊盘标识和器件来源信息的差异。相同 footprint 只写入一份，SchLib 的封装模型引用及 Footprint 参数同步指向实际保留的名称；启用独立导出时，单独的符号/封装库也保持配套。仅名称相同不能证明封装相同，不同内容会分别保留。已有库的条目、名称、附加数据和历史重复项保留，新增内容优先复用相同的已有封装。

每次合并只包含本次成功转换的勾选器件，重新下载会替换同名合并库，不追加以前的条目。单个器件或格式失败时其他成功内容仍保存，失败项在结果中说明；全部失败不覆盖旧库。停止时不写入尚未完成的合并库，已完成文件保留。已有逐器件库不会自动删除。

## 追加已有库与 PCB 工程

勾选 **Lib → 追加** 打开追加页面，之后可点击 **配置追加…** 修改。已有库可选择 `.SchLib`、`.PcbLib` 或两者；只指定一种时，主页锁定对应的 AD 格式，只将器件的符号或 PCB 封装追加到所选库，不生成另一种库。已有元件、模型及附加数据保留；同名符号保留原内容，相同 footprint 复用原条目，同名但不同的 footprint 加序号保存，结果详情显示跳过和复用数量。所选库需为受支持的二进制 AD 库（不超过 256 MiB）；无效文件或处理期间发生修改时停止写入。

追加页面的 **独立导出器件** 默认关闭：3D 文件集中到已有 SchLib 旁的 **“库名_3D”** 文件夹；只选 PcbLib 时跟随 PcbLib 名称并加 `_3D`。两份库位于不同目录时，优先跟随 SchLib。勾选后可选择 **器件导出目录**，额外的独立库与 3D 文件按“器件名_编号”保存；目录留空时使用 **PCB 工程所在文件夹**，未指定工程时使用优先库旁。独立目录不会改变集中库的位置。

目标文件下方的 **将指定库导入到PCB工程** 为独立按钮，功能为：**将上方指定lib导入到指定的PCB工程中。** 仅同时指定至少一份已有库和 `.PrjPcb` 时可用；点击后直接导入当前填写的文件，无须先确定配置，无须下载器件，也不受下载列表是否为空或是否勾选影响。重复导入跳过已有引用，结果直接显示在配置页。下载时仅追加已有库；升级前保存的导入勾选不再触发自动导入。

只指定 `.PrjPcb` 时，**工程配套库与 3D** 区域可分别选择 **3D 导出目录**、**SchLib 导出目录和库名**、**PcbLib 导出目录和库名**，支持中文名称和对应扩展名。库目录留空时使用工程所在文件夹，库名留空时使用工程名称。按主页选中的 AD 格式生成配套库并加入工程；同名库已存在时继续追加，保留原条目。指定已有库后，此区域收起，不影响所选已有库，已填的路径和库名保留。

3D 目录留空且未独立导出时，仍使用 SchLib（仅有 PcbLib 时为 PcbLib）旁的“库名_3D”目录；独立导出时，模型随器件保存。显式指定 3D 目录后，模型使用该目录，独立导出时在该目录下按器件分文件夹。工程中只引用集中库，额外的独立库不重复加入。

追加模式下，主页“保存到”路径和选择文件夹按钮持续为灰色，各导出路径在 **配置追加…** 中调整。普通导出目录仍记忆，取消追加后恢复可编辑；主页 **开始下载** 始终用于下载勾选器件，已有库导入统一通过配置页按钮执行。

工程只添加库文件引用，库仍保存在原位置，移动库后需更新工程引用。若 AD 已打开该工程，重新加载后查看新增库；此操作不放置元件到原理图或 PCB。工程与文件引用的概念见 [Altium 官方工程文档](https://www.altium.com/documentation/altium-designer/creating-projects-documents)。

默认在修改已有库与工程前备份原文件到 `%LOCALAPPDATA%/LCSC3D/backups/`，不在库或工程旁产生备份；可在 **设置 → 备份** 关闭自动备份、恢复或清理副本。取消、解析失败、文件占用或写入失败时提示错误，已成功导出的文件保留。已有库与单独输出的路径相同时会提示更换目录或关闭单独输出，防止覆盖原库。

## AD 元件库

勾选 SchLib 与 PcbLib 后，软件直接生成 AD 原生符号库和封装库，无须手动导出嘉立创EDA 的 ZIP，也无须安装 AD 才能生成。未选择合并时，文件保存在器件目录中；在 AD 中打开或安装这两份库，可从库面板选取器件。符号的 PCB 模型引用与 PcbLib 中的封装名称一致，默认按引脚和焊盘编号匹配。

C2765186 保留 14 个符号引脚、12 个贴片焊盘、4 个镀槽孔固定焊盘及 2 个非镀定位孔。组合编号（如 A1B12）不拆分；13、14 各对应两个焊盘，不去重。库保留相对原点、孔径、槽长、孔旋转、铜与孔的偏移、阻焊/锡膏扩展、厂商、C 编号及官方来源参数。

目前支持多单元符号，保留每个单元的原点、引脚归属和真实编号，引脚电气类型统一为 Passive；总览符号不混入子单元。支持常见引脚、矩形、折线、多边形、圆形、文字、贴片及多层矩形/圆形/椭圆焊盘，以及多边形自定义焊盘。自定义焊盘以编号电气锚点和关联的完整铜区域表示，保留孔、槽孔和阻焊/锡膏扩展；适用于原始数据中已有轮廓的凹形及不规则焊盘。曲线路径转换为线段或区域时，最大弦误差为约 0.00127 mm。多轮廓区域及暂不支持的图元会提示导出失败，不会生成缺图元的库；其他成功资源保留并显示“部分完成”。没有 3D 模型时仍可导出 AD 库。

PcbLib 支持内嵌 STEP，不生成 IntLib。回归包含 27 个官方 EDA→AD 样本，覆盖三/四单元符号、324 引脚 BGA、字母编号、凹形焊盘、槽孔及铜孔偏移，并使用独立 AD 库读取器核对实际坐标和属性；尚未完成 Altium Designer 实机放置验收。

需要 AD 中的三维封装效果时，开启“封装关联 3D 模型”。具体支持范围与原生验证边界见 [本版验证记录](../docs/2.4.0验证记录.md)。独立下载的官方 STEP 未作变换，手动添加时仍需核对坐标。

## 预览

载入列表后自动预览首个器件，右侧切换“3D 模型 / 符号 / 封装 / 商品图片”，无须先保存文件。

- 商品图片：显示商城商品原图，多图支持上一张/下一张；滚轮缩放、拖动平移，点击“适应窗口”恢复视野。无图片或加载失败会显示原因，可“重新加载”重试；切换器件后忽略过期响应。
- 3D：读取官方 OBJ 后由本地 WebGL 渲染，左键拖动旋转、滚轮缩放、右键拖动平移、双击或“适应窗口”恢复视野。
- 符号、封装：显示官方 SVG，保留图形、文字、焊盘/引脚编号与图层配色；滚轮缩放、左键平移、双击或“适应窗口”恢复视野，多单元符号可选择单元。
- 加载失败可点击“重新加载”，或者打开商城页面查看资源是否存在。

3D 初始视角让元件顶部朝上，正 Z 方向指向屏幕上方；切换器件、双击画布或点击“适应窗口”均恢复这个方向。3D 页面复用，本地画布不加载商城 3D 引擎或外部渲染库。快速切换器件会取消旧查询，并忽略过期结果。下载进度不重载预览，首次显示保留窗口稳定性处理。

## 检查更新与自更新

设置“关于与支持”页的“软件更新”区域显示当前版本，点击“检查更新”进入应用内更新页。关闭后返回前一页，检查使用已保存的代理选项；修改代理后应先保存。

软件启动、主窗口显示后自动后台检查一次本仓库的正式 GitHub Release。发现新版时在右上角显示通知，点击“查看更新”进入应用内更新页，展示版本、说明、大小和“下载并重启”；不会自动下载或安装。已是最新版、连接失败或接口异常时不弹窗，失败记录到日志。

点击“设置 → 关于与支持 → 检查更新”可手动查询，显示最新状态或失败原因，并可重试或打开发布页面。手动查询会收起启动提醒，重复进入会复用当前更新页；软件关闭时取消启动检查，后台网络等待不会阻碍退出。

便携 EXE 可点击“下载并重启”。软件在后台下载新版，与 Release 的 `SHA256SUMS.txt` 和 GitHub 附件 SHA-256（若提供）核对；校验通过后关闭当前窗口，独立更新进程等待程序退出、备份原 EXE、替换并启动新版。新版成功显示窗口后确认启动；替换或启动失败自动恢复原程序并提示错误。下载期间可取消，校验失败不修改原 EXE。

EXE 所在目录需要可写。更新保留 AppData 内的 `LCSC3D-settings.json` 和下载目录；暂存、失败记录及可恢复备份位于 `%LOCALAPPDATA%/LCSC3D/updates/.LCSC3D-update-*`，成功的暂存在后续启动时清理。下载模型期间可以检查版本，安装更新需等当前模型下载结束。

源码运行支持版本检查和打开发布页面，不自动替换 Python 或源码。2.0.0 起的后续正式发行须继续提供 `LCSC3D.exe` 与 `SHA256SUMS.txt`；预发行和草稿不作为自动更新版本。1.x 尚无自更新功能，首次升级到 2.0.0 请手动下载 EXE。

## 设置、网络与来源

设置记录在 `%LOCALAPPDATA%/LCSC3D/LCSC3D-settings.json`。SchLib/PcbLib 勾选状态单独保存；旧 WRL、旧符号或封装独选设置迁移为 STEP。旧版 EXE 旁的配置成功迁移到 AppData 后清除。设置与更新使用的内部 JSON 不属于资源导出，已有下载文件保留。

国内 `lceda.cn` 的官方器件与 SVG 接口优先，失败时回退 `easyeda.com` 官方镜像；3D 模型来自官方模型接口。最多同时处理 3 个器件，各资源受控并行；复用连接，网络资源缓存最多 16 MiB，覆盖下载跳过此缓存。几何核对与缩放副本另有最多 64 MiB 的进程内缓存，按文件摘要区分；最多两个 CAD 工作进程，每个任务最长 120 秒，支持取消。

资源下载、模型关联、OBJ 阅读器、WebGL 与 SVG 交互和更新由本项目实现；Python、Qt 等基础组件遵循各自许可证，见 `licenses/THIRD-PARTY.md`。项目采用 AGPL-3.0-or-later。

数据来源：[JLCEDA 官方库](https://lceda.cn/) / [EasyEDA 官方库](https://easyeda.com/)。软件许可证不替代模型、符号、封装的版权及使用条件。模型保持官方内容，软件界面与使用说明提供来源链接。

## 构建与验证

开发时无需发布即可测试更新：在源码仓库运行 `python scripts/local_update_test.py`，使用自动打开的隔离程序副本点击“设置 → 关于与支持 → 检查更新”→“下载并重启”；默认模拟 2.1.1 → 2.1.2，程序实际版本不修改。支持自动验证和校验失败场景，详见 [本地更新测试](../docs/本地更新测试.md)。普通启动仍从 GitHub 检查正式更新。

Windows x64、Python 3.12.10、PySide6 6.11.1、PyInstaller 6.20.0、urllib3 2.7.0。

```powershell
python -m pip install -r app/requirements-test.txt
python app/main.py
python -m unittest discover -s app/tests -v
.\app\build.ps1
```

`app/build.ps1` 构建后将最新 EXE 同步到 `outputs/LCSC3D.exe`，构建中间结果为 `work/dist/LCSC3D.exe`。联网成品验证：`LCSC3D.exe --self-test .\verification` 检查现有模型和预览流程；`LCSC3D.exe --self-test-ad .\verification-ad` 检查 C2765186 的 APP 勾选及实际 SchLib/PcbLib 导出，并保存界面与报告。追加 `--self-test-ad-parts C20197,C2765186` 可指定多个验证器件。追加 `--self-test-ad-merge` 验证实际界面的两个合并开关和自定义名称。完整发行及实际 EXE 自更新验证流程见根目录 `CONTRIBUTING.md`。

离线三维成品验证：在明确选择的验证目录 `fixtures/` 下准备公开的 `C2765186.json`、`source.step` 与 `source.obj`，运行 `LCSC3D.exe --self-test-models 验证目录`。验证默认关联、两种 KiCad 模式、AD 缩放、合并与副本、异常/无模型混合批次，生成 `model-verification.json` 及界面截图。请使用隔离的 `LOCALAPPDATA`。
