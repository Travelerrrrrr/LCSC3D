# LCSC3D 2.1.0 使用说明

Windows 10/11 x64 便携软件，用嘉立创商城 C 编号下载官方 STEP/OBJ 模型、导出原生 AD 符号与封装库，提供三类预览与自更新。运行文件固定为 `LCSC3D.exe`，源码包为 `LCSC3D.zip`，版本号单独显示。

## 商城搜索、价格与商品详情

点击主窗口的 **立创商城**，打开可独立切换、移动和最小化的商城窗口。在 **搜索商品** 中输入 C 编号、型号或关键词后按回车。列表展示 C 编号、型号、厂商和封装，选中元件查看完整商城参数、描述和可用资源。**数据手册**和**商城商品页**打开对应的官方链接。点击 **预览选中元件**，主窗口恢复并进入前台，按当前预览模式显示高亮行的 3D、符号或封装；商城窗口、当前行与勾选状态保留。

搜索列表新增 **单价 / 梯度** 和 **库存**。价格列下拉框列出该商品的真实阶梯，显示人民币单价及计价单位，例如 `1+ ¥0.011/个`。默认选择 1+，最低 5 个起订则默认显示 5+ 对应价格；若商城只提供更高起始梯度，选择最低可用梯度。每个商品独立切换，保留原始价格精度；翻页返回仍保留手动选择，开始新搜索恢复默认梯度。价格和现货库存随搜索页面取得，切换梯度即时显示。

库存显示商城搜索页的现货数量，缺货显示 `0`，缺少库存或报价显示 `—`。右侧商品型号、介绍及参数所在的文字详情区可上下滚动；介绍和长参数自动换行，参数行随文字高度调整。商品图片、原图入口及下方操作按钮保持可见。

搜索无需登录，每页最多 **50 个元件**，显示结果总数和当前页。点击 **上一页 / 下一页** 才获取目标页，列表仅保留当前页，避免一次加载全部商品。元件默认不勾选；跨页手动勾选会保留，点击 **加入下载列表** 导入本次搜索各页已勾选的元件。全选和反选只作用于当前页；开始新搜索会清除旧搜索的勾选。2026-10-08 实测「单片机」共 1,500 个结果，按软件每页 50 个展示为 30 页。

选中商品后点击右侧 **收藏到账号**，即可保存到登录账号的商城收藏，并在 **账号收藏** 列表看到该元件。重复收藏保留已有收藏。点击 **取消收藏** 移除当前商品的真实账号收藏，已导入的下载列表和已下载文件保留。尚未登录时先使用顶部 **账号登录**。

点击商品图片或 **查看全部原图** 打开软件自己的图片窗口，显示商品页的全部图片和缩略图。点击缩略图或「上一张 / 下一张」切换；滚轮或「放大 / 缩小」调整比例，拖动平移，「原始大小」按原始像素显示，双击或「适应窗口」恢复视野。左右方向键也可切换图片。关闭图片窗口后商城窗口保留。

## 登录、记住登录与账号收藏

1. 点击主窗口顶部 **账号登录**，按钮位于 **检查更新** 之前；登录状态与商城窗口共享。
2. 在原生登录框选择 **扫码登录 / 账号密码 / 手机验证码**。扫码用微信确认；账号密码直接在软件内输入；短信登录先获取验证码再提交。若商城要求图片验证，在同一登录框输入图中文字，支持 **换一张**。短信发送后有 60 秒重试倒计时。
3. **记住登录，下次启动自动恢复** 默认勾选。重启软件自动恢复并校验会话，无须重新登录；取消勾选则只在本次运行中保留登录。会话过期后需重新登录。
4. 打开 **立创商城 → 账号收藏**，已登录时自动获取收藏；也可点击 **获取收藏** 刷新。软件后台读取全部账号收藏，筛选框用于过滤已获取元件。
5. 收藏元件默认不勾选，勾选需要的元件并点击 **加入下载列表**，随后在主窗口选择格式并开始下载。收藏的导入、全选和反选只处理当前筛选中可见的元件。选中商品可单独取消账号收藏。

导入按 C 编号去重，已有元件的勾选状态、下载结果与当前预览行保留；新元件默认勾选。尚未载入的有效手动输入也会合并；输入框有无效内容时先修正再导入。下载期间不能修改队列，可等下载结束后导入。

记住登录使用 Windows 当前用户的 DPAPI 加密，文件位于 `%LOCALAPPDATA%/LCSC3D/store-session.bin`，不保存账号密码。它只供本机当前 Windows 用户恢复会话，不包含在源码包、交付目录或日志中。关闭商城窗口保留登录；**退出登录** 清除本程序当前会话、加密保存的登录状态和暂存的收藏，保留已导入的下载列表。

收藏后台获取可随时停止，停止或普通网络失败保留已获取的部分；账号登录失效会清除暂存的账号数据并提示重新登录。账号收藏的添加、取消均在服务器确认后更新列表，失败时保留现有数据。收藏读取最多 200 页、暂存 10,000 个有效 C 编号元件。商品搜索按需获取当前 50 个元件，不预取后续软件页。

本地回归覆盖价格精度、库存、最低起订量、独立梯度选择、完整文字与参数、删除勾选器件，以及已有登录、分页、收藏和预览。手机验证码和图片验证已经过真实账号验证；账号密码流程使用本地模拟服务验证。详见 [2.1.0 更新与验证](../docs/releases/v2.1.0.md)。

## 获取资源

下载列表的 **删除已勾选器件** 移除所有打勾的器件，同时更新输入框，保留未勾选器件的结果和已下载文件。若正在预览的器件被删除，会切换到剩余器件；列表清空时恢复预览占位。下载进行期间删除按钮不可用，任务结束后恢复。

1. 输入 C 编号，支持换行、空格、中英文逗号、分号；不区分大小写，重复编号自动合并。
2. 点击“载入列表”。后台查询全部器件型号，包括未勾选的器件；单击器件行切换右侧预览。
3. 在下载列勾选需要的器件，可使用“全选”“反选”。重新载入时按编号保留选择。
4. 选择保存目录与格式：3D 模型“STEP”“OBJ”，AD 元件库“SchLib”“PcbLib”。默认只选 STEP，可任意组合，也可只导出 AD 库。
5. 点击“开始下载”。任务仅处理勾选的器件，期间仍可操作预览；“停止”保留已完成文件。

下载目录保存所选的 STEP、OBJ、SchLib、PcbLib。STEP/OBJ 保持官方内容，AD 库从官方结构数据生成。已取消 JSON 和 SVG 文件导出，包括 model-info.json；不转换为 KiCad，不生成 WRL 或 CSV。

每个器件使用独立的“器件名_编号”目录，文件夹命名规则保持不变。AD 库文件仅使用元件型号命名，不附加 C 编号；STEP/OBJ 文件名保持原规则。文件名与目录名中的 Windows 禁用字符替换为下划线，缺少型号时使用“未命名器件”。例如：

```text
所选目录/
  RP2040_C2040/
    C2040_LQFN-56_L7.0-W7.0-P0.4-EP.step
    C2040_LQFN-56_L7.0-W7.0-P0.4-EP.obj
  TYPE-C 16PIN 2MD(073)_C2765186/
    TYPE-C 16PIN 2MD(073).SchLib
    TYPE-C 16PIN 2MD(073).PcbLib
```

每次下载固定重新获取所选资源并覆盖已有同名文件，界面不再提供“覆盖已有文件”选项。文件下载或生成成功后才替换，失败或取消时保留原文件；未选中的器件及格式不受影响。缺少 3D 模型时显示“无模型”，仍可预览可用的符号和封装。某种模型格式不可用时保留其他已完成格式并显示“部分完成”。停止会在当前网络读取结束后响应，读取超时 18 秒。已有文件不会因取消某种导出而自动删除。

## AD 元件库

勾选 SchLib 与 PcbLib 后，软件直接生成 AD 原生符号库和封装库，无须手动导出嘉立创EDA 的 ZIP，也无须安装 AD 才能生成。文件保存在器件目录中；在 AD 中打开或安装这两份库，可从库面板选取器件。符号的 PCB 模型引用与 PcbLib 中的封装名称一致，默认按引脚和焊盘编号匹配。

C2765186 保留 14 个符号引脚、12 个贴片焊盘、4 个镀槽孔固定焊盘及 2 个非镀定位孔。组合编号（如 A1B12）不拆分；13、14 各对应两个焊盘，不去重。库保留相对原点、孔径、槽长、孔旋转、铜与孔的偏移、阻焊/锡膏扩展、厂商、C 编号及官方来源参数。

目前支持多单元符号，保留每个单元的原点、引脚归属、真实编号和原始电气类型；总览符号不混入子单元。支持常见引脚、矩形、折线、多边形、圆形、文字、贴片及多层矩形/圆形/椭圆焊盘，以及多边形自定义焊盘。自定义焊盘以编号电气锚点和关联的完整铜区域表示，保留孔、槽孔和阻焊/锡膏扩展；适用于原始数据中已有轮廓的凹形及不规则焊盘。曲线路径转换为线段或区域时，最大弦误差为约 0.00127 mm。多轮廓区域及暂不支持的图元会提示导出失败，不会生成缺图元的库；其他成功资源保留并显示“部分完成”。没有 3D 模型时仍可导出 AD 库。

PcbLib 目前不内嵌或绑定 STEP 模型，不生成 IntLib。回归包含 27 个官方 EDA→AD 样本，覆盖三/四单元符号、324 引脚 BGA、字母编号、凹形焊盘、槽孔及铜孔偏移，并使用独立 AD 库读取器核对实际坐标和属性；尚未完成 Altium Designer 实机放置验收。

需要 AD 中的三维封装效果时，请在 PcbLib 编辑器中手动添加 3D Body 并导入下载的 STEP，核对 XYZ 位置、高度和旋转角度，必要时调整角度与偏移。官方独立模型的原点、坐标轴和摆放方向可能与 AD 封装坐标体系不同，而当前导出尚未转换官方 3D 关联及放置参数，因此模型导入后不一定直接对齐。后续版本会增加 3D 模型自动嵌入 PcbLib 的功能，并完善关联、位置和角度处理。

## 预览

载入列表后自动预览首个器件，右侧切换“3D 模型 / 符号 / 封装”，无须先保存文件。

- 3D：读取官方 OBJ 后由本地 WebGL 渲染，左键拖动旋转、滚轮缩放、右键拖动平移、双击或“适应窗口”恢复视野。
- 符号、封装：显示官方 SVG，保留图形、文字、焊盘/引脚编号与图层配色；滚轮缩放、左键平移、双击或“适应窗口”恢复视野，多单元符号可选择单元。
- 加载失败可点击“重新加载”，或者打开商城页面查看资源是否存在。

3D 初始视角让元件顶部朝上，正 Z 方向指向屏幕上方；切换器件、双击画布或点击“适应窗口”均恢复这个方向。3D 页面复用，本地画布不加载商城 3D 引擎或外部渲染库。快速切换器件会取消旧查询，并忽略过期结果。下载进度不重载预览，首次显示保留窗口稳定性处理。

## 检查更新与自更新

点击顶部“检查更新”，软件访问本仓库的正式 GitHub Release，显示新版版本、说明与大小。当前已是最新版时直接提示，网络失败可重试或打开发布页面。

便携 EXE 可点击“下载并重启”。软件在后台下载新版，与 Release 的 `SHA256SUMS.txt` 和 GitHub 附件 SHA-256（若提供）核对；校验通过后关闭当前窗口，独立更新进程等待程序退出、备份原 EXE、替换并启动新版。新版成功显示窗口后确认启动；替换或启动失败自动恢复原程序并提示错误。下载期间可取消，校验失败不修改原 EXE。

EXE 所在目录需要可写。更新保留 `LCSC3D-settings.json` 和下载目录；成功后清理临时更新目录，失败记录与可恢复的备份保留在同目录的 `.LCSC3D-update-*` 内。下载模型期间可以检查版本，安装更新需等当前模型下载结束。

源码运行支持版本检查和打开发布页面，不自动替换 Python 或源码。2.0.0 起的后续正式发行须继续提供 `LCSC3D.exe` 与 `SHA256SUMS.txt`；预发行和草稿不作为自动更新版本。1.x 尚无自更新功能，首次升级到 2.0.0 请手动下载 EXE。

## 设置、网络与来源

设置记录在 EXE 同目录的 `LCSC3D-settings.json`，目录不可写时不保存。SchLib/PcbLib 勾选状态单独保存；旧 WRL、旧符号或封装独选设置迁移为 STEP。设置与更新使用的内部 JSON 不属于资源导出，已有下载文件保留。

国内 `lceda.cn` 的官方器件与 SVG 接口优先，失败时回退 `easyeda.com` 官方镜像；3D 模型来自官方模型接口。最多同时处理 3 个器件，各资源受控并行；复用连接，当前进程最多缓存 16 MiB 器件与模型数据，覆盖下载跳过缓存。

资源下载、模型关联、OBJ 阅读器、WebGL 与 SVG 交互和更新由本项目实现；Python、Qt 等基础组件遵循各自许可证，见 `licenses/THIRD-PARTY.md`。项目采用 AGPL-3.0-or-later。

数据来源：[JLCEDA 官方库](https://lceda.cn/) / [EasyEDA 官方库](https://easyeda.com/)。软件许可证不替代模型、符号、封装的版权及使用条件。模型保持官方内容，软件界面与使用说明提供来源链接。

## 构建与验证

Windows x64、Python 3.12.10、PySide6 6.11.1、PyInstaller 6.20.0、urllib3 2.7.0。

```powershell
python -m pip install -r app/requirements-test.txt
python app/main.py
python -m unittest discover -s app/tests -v
.\app\build.ps1
```

构建结果为 `app/dist/LCSC3D.exe`。联网成品验证：`LCSC3D.exe --self-test .\verification` 检查现有模型和预览流程；`LCSC3D.exe --self-test-ad .\verification-ad` 检查 C2765186 的 APP 勾选及实际 SchLib/PcbLib 导出，并保存界面与报告。追加 `--self-test-ad-parts C20197,C2765186` 可指定多个验证器件。完整发行及实际 EXE 自更新验证流程见根目录 `CONTRIBUTING.md`。
