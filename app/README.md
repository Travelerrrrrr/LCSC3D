# LCSC3D

Windows x64 便携软件，当前版本 1.6.1。支持 STEP、WRL、OBJ 三种 3D 模型下载，以及右侧“3D 模型 / 符号 / 封装”预览。运行 EXE 即可使用，无须安装 Python、KiCad、AD、浏览器插件或额外浏览器运行时。

软件正式名称固定为 `LCSC3D`，不附加 Portable、Source、版本号或其他名称后缀。运行文件为 `LCSC3D.exe`，源码包为 `LCSC3D.zip`；版本号单独记录为版本信息。历史版本仅保留文档，不保留旧版程序和源码包。

符号、封装预览直接加载国内商城使用的官方 SVG，通过内置浏览器保留图形、文字和图层配色。首次在线预览防闪动修复、器件目录命名和无 CSV 输出均保留；仅导出 3D 模型。

## 使用

1. 输入立创 C 编号，支持换行、空格、中英文逗号和分号；编号不区分大小写，重复编号自动合并。
2. 点击“载入列表”，在“下载”列勾选需要下载的器件；新器件默认勾选，支持“全选”和“反选”，列表下方显示勾选数量。重新载入时按编号保留已有器件的勾选状态。
3. 选择保存目录和 3D 格式。默认 STEP，可选 WRL、OBJ；点击“开始下载”仅处理勾选的器件。未勾选任何器件时会提示；下载期间勾选框及全选、反选按钮暂时锁定。
4. 每个器件保存到独立的“器件名_编号”目录，例如 `RP2040_C2040`。结果和错误显示在下载列表中，进度与成功数量按本次勾选器件统计。
5. 载入列表后右侧自动预览首个器件；单击其他器件自动切换预览，通过右侧上方按钮切换 3D 模型、符号、封装。预览始终可操作，未勾选的器件也可预览，下载期间也可旋转、缩放和切换，无须额外点击预览按钮。

载入列表后，“型号 / 模型”列自动联网查询器件型号，无须先下载，未勾选器件也会查询。查询在后台进行，最多同时查询 3 个器件；将鼠标停在型号上可查看完整型号和关联模型名。查询期间显示“查询中…”，失败显示“查询失败”并提供错误提示，可点击“载入列表”重试。查询不保存模型文件、不计入下载进度，下载会复用已有器件信息缓存；更换列表会忽略旧查询结果。

预览可以在下载前使用：先“载入列表”，再选择器件。3D 使用商城官方在线查看器，鼠标拖动旋转、滚轮缩放。启动时先用本地空白页准备浏览器渲染器，载入列表或更换器件时自动加载查看器和模型；尚未载入器件时显示提示，加载失败可点击“重新加载”。下载进度和结果更新不会重载当前预览。软件未实现自有 3D 解析器；WRL 使用 easyeda2kicad 转换。

符号与封装预览直接读取商城数据手册弹窗使用的 SVG 接口：`https://lceda.cn/api/products/{C编号}/svgs`，国内接口请求失败时自动尝试 EasyEDA 的官方 SVG 镜像。软件使用原始 SVG 图形与样式，无需通过器件格式转换生成二维预览，也不使用商城的 PNG 缩略图。

两种二维预览支持滚轮缩放、鼠标左键拖动平移、“适应窗口”、双击恢复视野和多单元符号选择；封装保留官方焊盘编号与图层配色。符号与封装共用 SVG 缓存，来回切换可保持各自视野；点击“重新加载”重新查询。缺少一种预览数据时，另一种仍可使用。

## 性能

- 启动只准备 3D 渲染器；符号、封装画布在首次使用时初始化，并共用浏览器配置。
- 3D 查看器页面复用：切换器件直接通知官方引擎加载新模型，不重复加载引擎与界面脚本；快速切换只保留最新待加载器件，旧响应不会覆盖当前状态。“重新加载”会重建查看器以恢复异常状态。
- 器件与模型优先从国内官方接口取得，失败时回退到 EasyEDA 官方镜像。连接池复用 TLS/TCP 连接；最多同时处理 3 个器件，每个器件的 STEP 与 OBJ 并行取得，WRL 复用同一份 OBJ。
- 当前进程最多缓存 16 MiB 器件与模型原始数据：器件信息 10 分钟、模型数据 1 小时，不写入长期磁盘缓存。勾选“覆盖已有文件”会跳过缓存重新获取；停止请求仍会检查取消状态，退出软件释放缓存。
- 打包排除未用 QML 模块、调试资源、开发工具和多余浏览器语言包，保留中文、英文及所需 Qt、WebGL 运行库。仍是完整单文件 EXE。

示例输入：

```text
C2040
C20197, C163691
```

保存结构示例：

```text
所选目录/
  RP2040_C2040/
    C2040_LQFN-56_L7.0-W7.0-P0.4-EP.step
    C2040_LQFN-56_L7.0-W7.0-P0.4-EP.wrl
    C2040_LQFN-56_L7.0-W7.0-P0.4-EP.obj
    model-info.json
  4D03WGJ0102T5E_C20197/
    ...
```

仅保存勾选的 3D 格式和来源信息，不生成 CSV。器件名来自官方型号，Windows 禁用字符替换为下划线；缺少名称时使用 `未命名器件_编号`，编号后缀区分同名器件。

STEP 原样保存，适用于 SolidWorks、FreeCAD 等 CAD 软件；WRL 适用于 KiCad；OBJ 保存官方模型文本。默认保留已有非空文件，勾选“覆盖已有文件”可更新；零字节文件重新生成。各格式独立处理，某个格式不可用时，已保存的其他格式保留。

保存目录与格式记录在 EXE 同目录的 `LCSC3D-settings.json`；目录不可写时不保存设置。旧版仅选择符号或封装导出的设置会迁移为默认 STEP。浏览器使用临时目录，无须安装 WebView2。

下载和预览依赖网络及官方服务器。部分器件没有 3D 模型；软件显示“无模型”，仍可预览可用的二维数据。停止下载后当前网络读取结束时响应（读取超时为 18 秒），已完成文件保留。3D 预览需要支持 WebGL 的显卡驱动。

## 源码与构建

自有代码与 easyeda2kicad 均采用 AGPL-3.0。源码包包含 GUI、下载层、预览、测试、构建脚本、第三方说明与固定版本上游源码。

本版本使用 Python 3.12.10、PySide6 6.11.1、PyInstaller 6.20.0、urllib3 2.7.0，目标系统为 Windows 10/11 x64。在 Windows 安装 Python 3.12 后进入仓库或完整源码包的 `app/` 目录运行：

```powershell
.\build.ps1
```

构建结果为 `dist\LCSC3D.exe`。也可安装 requirements.txt 后执行 `python main.py`。构建不需要原生转换器、C++ 工具链或 Qt 开发包。

本地测试：`python -m unittest discover -s tests -v`。
联网成品验证：`LCSC3D.exe --self-test .\verification`。该检查下载前型号显示、全选、反选及勾选过滤，下载两个真实器件的三种 3D 格式、跳过一个未勾选器件、处理一个勾选的无效编号、切换三种预览并保存截图和 verification.json，完成后自动关闭。记录包含下载前型号、勾选与跳过编号、应用名称、窗口标题、主窗口句柄、隐藏事件、输出格式、CSV 检查、二维预览的引脚/焊盘数量和实际 SVG 来源接口。
