# LCSC3D 2.4.3 全面优化与验收

验证日期：2026-10-15。工作区基线为 `1c8ba25`，Windows x64、PowerShell 7、Python 3.12、PySide6 6.11.1。检查覆盖启动与配置、下载与取消、AD / KiCad 库和模型、预览、商城搜索与筛选、收藏、购物车、订单、备份、更新、UI 与日志诊断。账号流程使用本地模拟服务；联网检查仅读取公开商品、分类和模型资料。

## 优化与修复

- 购物车批量勾选集中更新一次合计，避免逐行重复扫描整表；数量与选择结果保持一致。
- 商品简介复用排版结果，最多保留 256 项、131072 个源字符，超过 4096 字符的单项不进入缓存。字体、宽度、内容与绘制设备 DPI 分别参与缓存识别，选择颜色随当前主题绘制。
- 命中磁盘主题缓存时不加载样式生成器；商城与下载列表关闭右键菜单后释放菜单和动作，避免长期累积。
- 修复刷新购物车丢弃 300 ms 延迟保存期间刚输入数量的问题。刷新会先完成明确的数量保存，再读取购物车；失败继续呈现核对提示。
- 修复取消分类刷新后，再次打开已有分类时刷新按钮不可用的问题。
- 修复收藏筛选隐藏当前行后，清除筛选未恢复当前商品详情的问题。
- 修复商品简介含补充平面 Unicode 字符时，Qt 的 UTF-16 偏移被当作 Python 字符索引，导致第二行漏字的问题。
- 英文设置导航使用 “About and support”，修正连接符被 Qt 当作快捷键标记的问题；实际 EXE 大字体截图确认文字完整。
- 日志目录扫描失败时仍生成环境诊断，在 `issues` 中明确标记原因；清除报告失败并保留文件，恢复访问后可以继续收集日志。
- 成品验收脚本支持独立的 `--verify-dir`，直接验证 `outputs/LCSC3D.exe` 时不再把文件复制到自身。

本轮没有删除格式、商城、预览、更新或备份功能。正式版本同时包含之前完成的表格布局、数字分页、系统字体与控件绘制调整，以及 AD 3D 模型机械层选择，完整介绍见 [版本说明](releases/v2.4.3.md)。

UI 对照在其他验收任务结束后顺序执行，使用相同合成数据和测量脚本，基线表格与绘制实现直接取自 `1c8ba25`。批量勾选测量 7 次，绘制测量 5 次，分别减少约 99.36% 和 33.46%。脚本同时核对勾选数量和金额，没有通过省略业务操作加速。

启动对照使用任务开始时的交付 EXE 与最终 EXE，各自使用独立的新配置目录。没有清空 Windows 文件缓存；工作集包含共享页，不能等同独占内存。启动差异较小，工作集和包体基本持平，不据此声称明显降低启动内存。本轮资源改进主要是避免菜单积累和重复初始化，并限制新增缓存容量。
