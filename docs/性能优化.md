# LCSC3D 1.5.0 性能优化记录

2026-10-06，在同一台 Windows x64 电脑上对比 1.4.1 与 1.5.0。正式名称与成品文件名始终为 LCSC3D / LCSC3D.exe，旧版只保留文字记录。

## 实测结果

| 指标 | 优化前 | 优化后 | 变化 |
| --- | ---: | ---: | ---: |
| 启动至主窗口可见，3 轮中位数 | 4.585 秒 | 2.566 秒 | 耗时减少 44.0% |
| 两个器件、三种格式下载，关闭应用缓存，3 轮中位数 | 3.202 秒 | 0.482 秒 | 耗时减少 84.9% |
| EXE 文件大小 | 220,452,159 字节（210.2 MiB） | 144,037,955 字节（137.4 MiB） | 缩小 34.7% |
| 单文件运行时解压内容 | 590,135,930 字节 | 347,626,178 字节 | 减少 41.1% |
| 归档条目 | 3,008 | 180 | 减少 94.0% |
| 启动后进程总工作集，3 轮中位数 | 460.5 MiB | 347.6 MiB | 减少 24.5% |
| 启动后应用及子进程数量 | 4 | 2 | 减少 2 个 |

新版实际 EXE 的官方 3D 查看器首次模型加载为 2.239 秒，切换到第二个模型为 0.158 秒；两次均 ready，查看器页面仅载入一次。此项是本轮成品观测值，未记录旧版同条件的查看器切换耗时，不据此推算百分比。

## 实现

1. **精简打包**：排除 QML 插件、未用 Python 绑定、浏览器调试包、开发工具和多余语言文件。保留 WebEngine 依赖的原生 Qt DLL、打印与 WebChannel 绑定、中文/英文资源和软件 OpenGL 回退。仍是包含完整浏览器运行库的独立单文件 EXE。
2. **按需初始化**：启动仅预热 3D 渲染器；符号和封装画布首次使用时创建页面，共用浏览器配置，HTTP 内存缓存上限 8 MiB。保留首次预览不隐藏、不重建主窗口的修复。
3. **复用 3D 查看器**：保留官方引擎页面，切换器件通过官方消息总线加载新模型，避免重新载入脚本与引擎。加载期间只保留最新待加载器件；按编号与请求序号过滤旧回调。手动重新加载或渲染器异常时可重建页面。
4. **优化下载**：优先使用国内官方器件、STEP、OBJ 接口；失败回退官方镜像。urllib3 连接池复用 TCP/TLS 连接，SSL 验证保持启用。最多并发 3 个器件，任务队列只提交正在处理的数量；STEP 与 OBJ 并行，WRL 使用同一份 OBJ，缺失或失败时也不重复请求 OBJ。
5. **限制缓存**：器件和模型原始数据最多 16 MiB，按最近使用淘汰，器件信息有效期 10 分钟、模型 1 小时；不新增长期磁盘缓存，取消状态在缓存命中时仍生效。“覆盖已有文件”跳过缓存。
6. **修正并发 UI**：结果按原始器件顺序汇总，进度按实际完成数量更新；旧进度消息不会覆盖完成状态。下载期间预览可继续操作。

## 验证与范围

- 51 项本地测试通过，涵盖原功能、真实 HTTP keep-alive/gzip、国内接口与镜像回退、格式并发、OBJ 复用、取消、缓存上限与过期、覆盖跳过缓存、乱序完成、查看器复用及旧回调、生产查看器脚本的快速切换队列、按需画布与原有窗口稳定性。
- EXE 从独立中文目录运行，清除 Python/Qt 环境变量，PATH 仅保留 Windows 系统目录；C2040、C20197 成功导出 STEP、WRL、OBJ，无效编号正确失败。官方 3D、符号、封装预览通过，主窗口句柄不变，无 Hide/WinIdChange 事件。
- 两个器件的六个模型文件与 1.4.1 实际成品输出逐字节一致；来源信息仍随文件保存，无 CSV、SchLib 或 PcbLib 输出。
- 原始测量数据见 [performance](performance/)，成品使用与验证见 [使用说明](../app/README.md) 和 [验证记录](验证记录.md)。
- 启动时间以新主窗口可见为终点；在可见后等待 1 秒，统计应用进程及其子进程 RSS 的总和。RSS 包含共享页面，该指标不是整机物理内存增量。启动没有清空 Windows 文件缓存，也不是系统冷开机测试。
- 下载使用真实 C2040、C20197，每轮均写入全新的临时目录，六个文件均成功；优化后明确关闭应用的数据缓存，HTTP 连接池仍可复用连接。网络、服务器/CDN 缓存、器件大小及系统负载会影响耗时，以上数值描述本机本轮观测。

## 复测

在仓库根目录，使用构建环境运行，`psutil` 仅供测量工具使用，不是应用运行依赖：

```powershell
python -m pip install psutil==7.2.2
python scripts/measure_performance.py startup --runs 3 --output work/performance/startup.json
python scripts/measure_performance.py downloads --runs 3 --output work/performance/downloads.json
python scripts/measure_performance.py bundle --output work/performance/bundle.json
python scripts/verify_portable.py
```

测量工具位于仓库 `scripts/measure_performance.py`。重复验证会重建生成的验证结果目录，结束时移除临时 EXE 副本；保留正式 `outputs/LCSC3D.exe`。
