# LCSC3D 2.4.3 验证记录

本次围绕用户提出的五项使用体验需求开发，基于 `125a314`，使用 PowerShell 7 和隔离的用户数据目录验证。

## 行为与界面检查

- 工作台“结果”列在改变窗口、调整分栏、出现垂直滚动条时填充到右边界；用户手动调整的型号列宽在切换主题后保留。
- 备份“大小”列用真实鼠标向左、向右拖动验证，宽度分别缩小和放大，“原位置”列不反向挤压。
- 分类初次打开与切换分组后默认折叠；搜索仍可找到下级分类并进入商品列表。
- 搜索、收藏、购物车、订单商品明细统一使用多行简介；品牌、封装、类别与已有参数来自原有响应。缺少简介明确占位，不虚构描述、不额外逐行请求。
- 数量及梯度价格控件在加高的行中保持正常高度；纯文本简介按宽度换行和省略，悬停保留完整介绍。
- 页码排列覆盖首尾、中段、省略号、空列表、单页、百万页数和大字体窄窗口。当前页不会因重复点击取消描边；直接跳到末页、返回前页后跨页勾选继续保留。
- 浅色、深色、中文与英文大字体进行界面截图检查。参考材料保存在忽略目录 `work/v2.4.3/`。

## 日志与交付检查

新增分页事件仅记录来源和页码，商品简介、搜索词与订单正文不进入日志。请求失败和界面回调沿用现有错误诊断。验证使用合成账号及本地服务，不读取真实登录凭据。

完整回归通过 **754 项测试**，耗时 301.210 秒。工作台专项的 7 项测试另核对了最终列宽保留行为。Ruff 的未定义名称、重复定义、异常控制流等重点检查通过，新增模块的 F 系列检查通过。

实际 EXE 的 **20 项验收全部通过，错误为 0**，包括设置与日志、备份、导出控件、AD / KiCad、商城、外观、公开资源与分类、购物车与订单、进度、模型、便携路径、应用数据目录，以及更新成功、校验失败、无更新、检查失败和启动检查。
