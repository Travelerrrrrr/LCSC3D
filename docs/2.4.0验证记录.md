# 2.4.0 下载进度、消息页与通知堆叠

验证日期：2026-10-13。本地开发交付，不发布 Release。

## 行为

进度从只统计最终器件数改为统计查询、解析、模型准备、各导出格式、合并及最终写库阶段。普通单器件、并发批量、AD 合并/追加、保留独立副本、KiCad 合并/独立导出使用同一单调进度聚合器。后台通过独立数值信号推送，界面以 320 毫秒 OutCubic 动画平滑到新目标；百分比显示与实际绘制同步。进度是处理阶段比例而非 HTTP 字节比例，不在网络等待期间自行跑完。任务所有处理及提交结束才到 100%；取消保留当前进度，重新下载立即归零并停止旧动画。

左侧“立创商城”下新增“消息”，保持单窗口页面和返回导航。显示通知时间、类型、标题及完整内容/详情，支持搜索、类型筛选、复制和清空。记录从新到旧，关闭弹窗不删除记录。历史位于 `%LOCALAPPDATA%/LCSC3D/messages/history.json`，最多 500 条且文件不超过 1 MiB，原子写入；文件损坏或写入失败记录结构化日志，当前通知仍能显示。历史不保存按钮回调，旧确认通知不具备执行操作的能力。

现有通知统一由 NotificationCenter 定位在主窗口右上角，避开标题栏。新通知在顶部滑入，之前的通知以动画下移；最多显示三条，小窗口无法容纳时收起更早的通知，全部通知仍在消息页。窗口缩放重新排布。取消、完成、模型提醒、队列输入/导出校验、更新结果和日志打包/清除结果均通过该通道显示；页面内的实时进度和表单状态仍保留。

本版不调整缓存，不更改已通过用户 AD 实测的 STEP 放置、尺寸或缩放规则。

## 代码目录与版本

应用的 63 个实现模块迁入 `app/lcsc3d/`，按 core、services、eda、models、ui、selftests 六个目录管理；增加统一资源根目录模块。内部使用完整包路径，更新测试的导入及替换路径、版本检查、发行工作流与递归打包审计。按迁移前快照核对日志事件编号与更新助手文件名，保持既有诊断及更新标识不变。源码入口和 EXE 引导入口仍保留在 app 根目录。

最终版本为 2.4.0，Windows 版本资源为 2.4.0.0。此任务同步分支，但不创建 Release 或标签；在线下载链接仍指向已发布的版本。

## 日志覆盖

增加阶段进度、处理终止、通知创建/关闭、动作点击及失败、历史载入/写入失败、消息页打开/复制/清空的结构化事件。后台进度继承批次 root_id；不为每帧动画写日志，阶段进度以百分比区段记录。通知日志保存编号、类型、字数和操作序号，不把可见消息正文、账号凭据或导出目录写入诊断字段。

消息历史独立于诊断日志：诊断 ZIP 保持既有明确文件/字段范围，不收集消息正文；清除日志保留消息记录，清空消息不删除诊断日志。验证使用隔离 LOCALAPPDATA，不读取真实用户登录凭据。已有轮转、异常链、崩溃线程捕获与更新助手日志策略继续保持。
