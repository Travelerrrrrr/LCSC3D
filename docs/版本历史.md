# LCSC3D 版本历史

## 2.4.0-demo.2（本地修复）

- 修复 C2861386 等官方 JSON 中旧模型原点与新封装坐标混用，造成模型偏移及“明显远离封装”提醒的问题。
- 复现标准版放入 PCB 时按模型外框更新原点的规则，保留实际偏置、旋转、高度及尺寸；不依据焊盘位置猜测居中。
- C57113、C83790 同类问题纳入回归；补充公开样本、提取官方函数的受控回放与成品坐标核对。
- [验证记录](2.4.0-demo.2验证记录.md)

## 2.4.0-demo.1（本地功能预览）

- 默认开启封装关联 3D，沿用标准版官方接口与放置参数，无需单独勾选 STEP 下载。
- IR 1.2 分离模型资源、放置请求和已核对变换，兼容原 1.0/1.1 文档。
- AD 内嵌 STEP；KiCad 9/10 内嵌模型，KiCad 8 提供外部模型兼容模式。
- 单器件、合并、独立副本与 AD 追加保留模型；封装去重同时比较模型内容与放置。
- 参数或几何基准无法确认时跳过模型并保留二维导出；可疑有效参数保持原样。批次滑动弹窗支持复制编号和原因。
- [实现边界](3D模型放置.md) · [验证记录](2.4.0-demo.1验证记录.md)

## 2.3.0

- 正式加入 KiCad 8+ 符号与封装导出，目标配置分别记忆，支持独立库、分别合并和单器件副本。
- 引脚电气类型可配置，矩形使用直角与实心主体背景填充，预览固定为 KiCad 风格。
- 版本化 EDA 中间层保留电气与几何语义，IR 1.1 支持过孔并兼容旧 1.0 数据。
- 修正引脚方向，支持封装过孔，修复长文本重叠、控制栏间距和合并闪动。
- AD/KiCad 普通导出与合并按本次选择覆盖同名库；AD 追加保留已有库成员。
- 包含原 2.2.2 开发改进：工程输出目录、库名与直接导入，以及商品缩略图、20 项分页和 AD 符号风格。
- 完善导出日志与故障恢复，验证诊断包、清除后续写与崩溃捕获。
- [更新说明](releases/v2.3.0.md) · [验证记录](2.3.0验证记录.md)

## 2.3.0-demo.4（本地功能预览）

- 支持 C31966 等封装中的贯穿过孔，AD 输出原生 VIA，KiCad 保留为无编号镀通孔。
- IR 1.1 新增 Via，继续读取原 1.0 文档；未知图元显示具体类型并提供结构化诊断。
- 合并开关在绘制前完成尺寸调整，修复控制栏闪动。
- 补齐 KiCad 转换、替换、回滚和逐格式日志，验证日志白名单收集、清理后续写与崩溃捕获。
- [更新说明](releases/v2.3.0-demo.4.md) · [日志审查](日志覆盖审查.md) · [验证记录](2.3.0-demo.4验证记录.md)

## 2.3.0-demo.3（本地功能预览）

- 修正来源路径反向时的引脚连接端，AD/KiCad 实际导出和 AD 延长预览同步修复。
- 长结果文字按实际换行高度排版，下载列表、预览与底部导出设置保持间距。
- KiCad 矩形改用直角，继续使用实心主体背景填充。
- KiCad 与 AD 共用合并操作方式：分别命名符号/封装库、保留独立器件、按选择组织 3D 目录；KiCad 没有追加模式。
- AD/KiCad 普通导出与再次合并覆盖同名库，以本次选择为准；KiCad `.pretty` 清除旧成员。AD 追加继续保留原库成员。
- [更新说明](releases/v2.3.0-demo.3.md) · [验证记录](2.3.0-demo.3验证记录.md)

## 2.3.0-demo.2（本地功能预览）

- 增加“导出到”目标选择，AD 和 KiCad 配置分别显示并记忆。
- KiCad 引脚默认跟随 IR 电气类型，可统一覆盖；无法映射的值回退为未指定。
- 矩形统一使用实心主体背景填充，KiCad 目标下固定显示 KiCad 符号预览风格。
- 符号库与封装库支持独立合并，四种组合均保持正确封装引用。
- [更新说明](releases/v2.3.0-demo.2.md) · [架构说明](EDA中间层.md)

## 2.3.0-demo.1（本地功能预览）

- 增加 KiCad 符号、封装、批量合并和共享封装引用；支持与 AD 同时导出。
- 引入版本化 EDA IR、源图元保留及目标能力检查，为后续 EDA 适配提供兼容基础。
- 首版新建 KiCad 库，保留同名目标；不自动注册工程库或绑定 3D。
- [更新说明](releases/v2.3.0-demo.1.md) · [架构说明](EDA中间层.md)


2026-10-06 起，软件正式名称固定为 **LCSC3D**。主窗口标题、界面标题、应用名称和构建名称均使用 LCSC3D，不附加 Portable、Source、版本号或其他后缀。本次正式发行版本为 **2.3.0**，版本信息单独显示。

最新本地交付固定为 `outputs/LCSC3D.exe` 和源码包 `outputs/LCSC3D.zip`，源码包根目录为 `LCSC3D/`。使用 `outputs/v版本号/` 暂存发行文件时，同步根目录 EXE、源码包、说明与校验和，保持最新交付入口一致。

2.1.0 正式整合独立商城窗口、50 条分页、价格梯度与库存、账号收藏添加/取消、完整介绍和参数、全部原图，以及三种原生登录与加密记住登录。下载列表新增删除勾选器件。README 使用正式程序自行生成的新截图。见 [2.1.0 发行说明](releases/v2.1.0.md)。

开发期间的本地 Demo 仍分别放在 `outputs/demo-2.1.0*/`，作为历史验证保留；正式发行使用 `LCSC3D.exe`、`LCSC3D.zip` 与 `SHA256SUMS.txt`。

上一版独立窗口与三种登录见 [2.1.0-demo.4](releases/v2.1.0-demo.4.md)，统一入口与完整商品资料见 [2.1.0-demo.3](releases/v2.1.0-demo.3.md)，原生扫码与登录保存版本见 [2.1.0-demo.2](releases/v2.1.0-demo.2.md)，第一版网页操作 Demo 的历史记录见 [2.1.0-demo.1](releases/v2.1.0-demo.1.md)。
