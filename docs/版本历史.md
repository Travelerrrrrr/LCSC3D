# LCSC3D 版本历史

2026-10-06 起，软件正式名称固定为 **LCSC3D**。主窗口标题、界面标题、应用名称和构建名称均使用 LCSC3D，不附加 Portable、Source、版本号或其他后缀。当前本地交付为 **2.1.3**，版本信息单独显示。本次仅本地提交，未发布 Release。

当前交付仅保留 `outputs/LCSC3D.exe` 和源码包 `outputs/LCSC3D.zip`，源码包根目录为 `LCSC3D/`。后续构建沿用这两个文件名，替换当前交付，不再并列保留多个发行版本。

2.1.0 正式整合独立商城窗口、50 条分页、价格梯度与库存、账号收藏添加/取消、完整介绍和参数、全部原图，以及三种原生登录与加密记住登录。下载列表新增删除勾选器件。README 使用正式程序自行生成的新截图。见 [2.1.0 发行说明](releases/v2.1.0.md)。

开发期间的本地 Demo 仍分别放在 `outputs/demo-2.1.0*/`，作为历史验证保留；正式发行使用 `LCSC3D.exe`、`LCSC3D.zip` 与 `SHA256SUMS.txt`。

上一版独立窗口与三种登录见 [2.1.0-demo.4](releases/v2.1.0-demo.4.md)，统一入口与完整商品资料见 [2.1.0-demo.3](releases/v2.1.0-demo.3.md)，原生扫码与登录保存版本见 [2.1.0-demo.2](releases/v2.1.0-demo.2.md)，第一版网页操作 Demo 的历史记录见 [2.1.0-demo.1](releases/v2.1.0-demo.1.md)。

历史版本只保留本目录下的文字记录：使用说明、验证记录与当时的 SHA-256 信息。旧版 EXE、源码 ZIP、截图、构建目录和源码/成品验证副本已清理；历史文档中提到的旧文件名、路径、功能和验证结论仅描述当时状态，不代表当前仍提供这些文件。Git 历史不改写。
