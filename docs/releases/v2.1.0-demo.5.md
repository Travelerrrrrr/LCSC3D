# LCSC3D 2.1.0-demo.5 · 完整详情、阶梯价格与下载列表删除

开发日期：2026-10-08。基于 2.1.0-demo.4，交付目录为 `outputs/demo-2.1.0-demo.5/`，运行文件 `LCSC3D.exe`，源码包 `LCSC3D.zip`。本地 Demo，保留正式版和之前的 Demo。

## 本次修改

1. **商品介绍完整显示。** 原介绍标签被限制在 76 像素内，较长内容会截断。本版取消高度限制，型号、介绍与参数放入可滚动的文字详情区；图片、原图入口和下方操作按钮保持可见。
2. **长参数完整换行。** 参数值不再以省略号截断，按列宽自动换行并调整行高；窗口或列宽改变后重新排版。截图中的 C499531「功能特性」可完整阅读。
3. **价格与库存列。** 搜索结果新增「单价 / 梯度」和「库存」。每个商品独立使用下拉框选择商城实际的人民币单价阶梯，按商品计价单位显示并保留原始精度。库存读取商城搜索页的现货数量；零库存显示 0，缺少报价或库存显示 —。
4. **最低起订量与翻页。** 默认使用 1+；若商品最低 5 个起订，显示 5+ 对应单价，跳过无法购买的更低数量；若只提供更高起始阶梯，则选最低可用阶梯。翻页保留该商品手动选择，新搜索恢复默认。每页仍最多 50 个元件，价格和库存随搜索结果读取，切换梯度即时显示。
5. **删除勾选的下载器件。** 主窗口新增「删除已勾选器件」，只移除下载列表及输入框中的对应编号。未勾选器件的结果和已下载文件保留，未载入的手动输入保留；删除当前预览器件时切换到剩余器件，删空时恢复占位。下载期间按钮禁用，取消的旧型号查询与模型响应不会重新填回已删除器件。

原有独立商城窗口、预览后主窗口进入前台、账号收藏添加/取消、商品原图、三种原生登录与加密记住登录继续保留。
