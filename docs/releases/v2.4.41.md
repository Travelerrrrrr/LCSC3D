# LCSC3D 2.4.41

本版改善已有 Altium Designer 元件库的名称编码兼容性，修复追加器件被误跳过及复用旧封装后独立 PcbLib 导出失败的问题。

## 已有 AD 库追加

- 对照库内实际存储目录识别 GBK、GB18030、UTF-8 等名称，兼容中文、Ω、±、特殊字符、长名称和显式存储别名。旧名称的原始字节、既有器件、模型和未知数据流保持原样。
- 修复部分中文名称被错误判为其他器件重名的问题，例如旧名称「逜」不再导致新器件 `ssA` 被跳过。
- 修复「東」等名称中的多字节尾字节被误当成参数分隔符的问题；名称中包含 `A=B`、`Weight=4`、`COMPCOUNT=0` 等文本时，保留完整名称及正确的条目数量。
- 追加时保留未修改字段的大小写、未知内容及重复字段。遇到存储映射歧义或索引不一致时明确拒绝操作，保留原文件。

## 独立封装与诊断

- 复用旧 GBK 封装时，合并库和独立 PcbLib 使用一致的安全存储映射，独立 SchLib 的封装引用同步保留。
- 补充名称边界、重复追加、原始数据保留和独立文件引用回归，核对日志打包、清除后继续记录及错误诊断能力。
