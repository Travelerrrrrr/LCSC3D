# LCSC3D 2.1.2

- **更新入口移入设置**：主窗口点击“设置”，在“软件更新”区域查看当前版本并检查新版；下载、校验、重启与失败恢复流程保留。启动后台检查继续在发现新版时提醒。
- **独立合并 SchLib / PcbLib**：下载格式下方新增“合并 .SchLib”“合并 .PcbLib”两个勾选框，可分别选择并自定义库名称，默认不合并。开关与名称自动记忆，下载期间锁定。
- **自定义库名**：支持中文名称和可选扩展名，校验无效路径、Windows 禁用字符及设备名。合并库保存在所选保存目录根部；未合并的格式仍放在各器件目录，STEP/OBJ 保持原有规则。
- **多器件原生库**：每份合并库包含本次成功转换的勾选器件。内部条目名带 C 编号，超长名称截短以适配原生库的存储限制，避免同型号、共享封装及长名称覆盖；保留引脚、焊盘几何、多单元结构、字体及符号到封装的引用。只合并一种库时仍保持配套引用。
- **完成后替换**：重新合并替换同名库，不追加旧条目。单个器件或格式失败时保留其他成功资源并逐项提示；全部失败、取消或写入失败不覆盖尚未完成的合并库。已经完成的文件保留。

## 细节优化

- 合并 SchLib、PcbLib 时可分别勾选“同时单独输出”，保留逐器件的配套库。
- “库与工程…”支持追加到指定的已有二进制 AD 库，保留原有条目、模型及附加内容，同名条目保留并跳过。
- 可将下载成功的库自动加入指定 `.PrjPcb`，也可直接导入已有库；重复引用跳过，工程原有设置和编码保留。修改前备份到 AppData，处理期间文件改变会中止写入。
- 商城“加入下载列表”后弹窗显示新增、跳过或失败原因。
- 主页“器件预览”新增“商品图片”，支持多张原图、缩放、平移、适应窗口与重新加载，快速切换器件不会显示过期图片。

350 项本地回归通过。实际 EXE 使用 C2040、C20197、C2765186 验证合并开关及两份自定义名称的库，独立读取器检查各条目的引脚、焊盘及引用。设置、便携运行与从设置发起的实际下载重启验证见 [成品验证记录](../验证记录.md)。合并库尚未经过 Altium Designer 实机打开验收；PcbLib 仍不内嵌 3D 模型。
