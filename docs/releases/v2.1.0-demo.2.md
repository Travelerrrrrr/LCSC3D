# LCSC3D 2.1.0-demo.2 · 原生商城功能

开发日期：2026-10-08。此本地 Demo 基于 2.0.0，新增原生商城功能，不发布为正式 Release。

## 使用

打开 `outputs/demo-2.1.0/LCSC3D.exe`。点击 **搜索商品…** 按 C 编号、型号或关键词查找元件，在软件内查看图片、参数、厂商、封装、数据手册链接及资源关联。点击 **预览选中元件** 使用主窗口的三类预览，或勾选 **加入下载列表**。

点击 **商城收藏… → 扫码登录**，在软件自己的登录框扫描官方微信二维码，并在手机上确认。**记住登录**默认勾选，重启后打开商城功能即可自动恢复并校验会话；失效时重新扫码。登录成功后自动获取商城账号收藏，从第一页后台处理分页。**获取收藏**可刷新，筛选框过滤已获取列表，勾选后加入下载列表。

## 行为

- 登录、搜索、商品详情、账号收藏使用原生 Qt Widgets 界面。商城认证和数据请求在后台完成，用户无需操作网页或手动翻页。
- 使用商城官方公众号二维码、扫码状态、授权确认和商城会话接口；支持 `SUCCESS` 成功状态，扫码后验证真实商城账号会话才显示已登录。
- 收藏使用账号接口 `/member/favorite/v3`，识别 `currPage/pageRow/totalRow/dataList`，自动分页、合并重复编号；异常分页、取消或上限会停止并保留已经获取的部分。
- 搜索无需登录，来自嘉立创EDA 官方商城元件目录；技术参数、图片和资料链接不代表实时成交价或库存。
- 勾选导入按 C 编号去重，保留原有下载结果、勾选状态及预览行，合并尚未载入的有效手动输入；下载期间禁止导入。筛选后仅导入可见的勾选元件。
- 已记住的登录会话由 Windows 当前用户 DPAPI 加密，保存为 `%LOCALAPPDATA%/LCSC3D/store-session.bin`，不保存密码。不勾选时仅在本次运行中保留登录。退出登录清除加密文件、当前会话和暂存账号收藏，保留下载列表。
- 后台请求支持取消，搜索或账号切换忽略旧响应；关闭软件等待活动请求结束，避免销毁正在运行的线程。

## 实号验证

用户在本次联调中扫码确认登录，软件验证商城账号会话成功，并实际读取 **13 个账号收藏元件**。随后关闭并重新启动源码程序，**无需再次扫码，成功恢复账号并再次读取同样的 13 个元件**。验证报告只记录状态和数量，不包含账号身份、Cookie 或授权码。

本地 HTTP 模拟覆盖两页收藏、重复编号、空收藏、取消、异常分页和会话失效；原生窗口覆盖搜索详情、勾选导入、队列保留、下载期间锁定、扫码取消与刷新、旧响应过滤。DPAPI 回归覆盖实际加密、客户端重建、损坏文件和退出后的旧保存任务。

177 项完整回归通过，其中 42 项商城专项回归。记住登录同时申请官方自动登录会话；已有商城会话过期而官方登录仍有效时，在后台换取新的商城会话，无需再次扫码。

Windows 单文件 EXE 已在独立中文目录运行，清除 Python/Qt 环境变量并将 PATH 限制为系统目录，三项验证均退出码 0：

- `--self-test-store`：原生搜索与扫码、两页收藏、勾选导入、去重、保留已有下载结果、DPAPI 加密、重建窗口后免扫码恢复和退出清除。
- `--self-test-store-live`：实际 EXE 直接恢复本次用户保存的登录，读取 13 个真实收藏并勾选导入；在线搜索 C2040 返回 14 个结果，精确元件、技术参数和图片正常。
- `--self-test`：C2040/C20197 的 STEP 和 OBJ 实际在线下载成功；3D、符号和封装预览通过，未勾选元件不下载，无效编号按预期失败，主窗口句柄保持稳定。

原始验证位于 `work/原生商城demo便携验证/`，交付包内的 `验证/` 保存报告和离线界面截图。已核对正式版 EXE 的 SHA-256，未被本次 Demo 修改。

账号需要额外绑定或身份验证的登录分支尚未实现；当前原生登录优先支持已完成绑定的微信扫码账号。官方接口变化可能需要适配。加密会话只能由本机当前 Windows 用户恢复，商城服务端仍可使登录失效。
