# LCSC3D 2.4.1：性能与内存优化（本地交付）

2.4.1 保持现有导出格式、模型原始尺寸和放置规则，重点优化大批量处理、预览与商城浏览。

- 缩略图更新不再反复统计整张收藏表，批量进度按增量计算。
- 同批次复用相同模型的下载、放置基准、校验与压缩结果；下一批重新获取，缓存设有容量上限。
- 3D 预览使用双精度连续缓冲区和后台编码，减少 Python 对象与 JavaScript 临时数组，绘制确认后释放传输数据。
- 商城复用网络连接，原图后台解码，图片缓存按实际像素限制，大收藏列表按视口预取。
- 账号恢复与商城控件构建分离，消息搜索复用表格项，备份列表后台读取。
- 精简未使用的 PDF 图像插件及运行库，保留现有浏览器渲染和软件 OpenGL 兼容路径。

本次交付包含 `LCSC3D.exe`、完整源码 `LCSC3D.zip`、使用说明和 SHA-256 清单，固定最新应用入口为 `outputs/LCSC3D.exe`。本地提交和构建不代表已发布 GitHub Release。

验证详情见 [2.4.1 验证记录](../2.4.1验证记录.md)。
