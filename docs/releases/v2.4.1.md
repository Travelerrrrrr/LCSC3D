# LCSC3D 2.4.1

## 商城选型与采购

- 商城提供“搜索商品 / 我的收藏 / 购物车 / 我的订单”四个原生页签。
- 搜索加入官方分类和筛选，支持品牌、封装、参数多选与数值范围、价格、需求数量、排序、现货、数据手册和品牌来源；分类和筛选在原搜索区域内展示。
- 搜索与收藏支持行内数量输入和右键快捷操作，可按各行数量批量加入购物车，也可添加到收藏或下载列表。数量按器件起订量和最小递增量调整，搜索单价随数量匹配，并支持查看全部价格区间。
- 购物车支持商品预览图、数量自动保存、勾选、移除和导入下载列表。“跳转到购物车”使用系统浏览器打开官方购物车，继续确认订单和付款。
- 我的订单支持分页、关键词和状态筛选；点击订单，在原表格区域查看商品图片、器件和物品、数量、单价与金额，并可勾选器件加入下载列表。返回保留列表位置，完整订单入口位于明细页内。

## 修复与界面调整

- 修复部分器件的数据手册缺失，兼容商城新版资料字段、厂商链接和旧版 PDF，缺失时补充官方元件目录资料。
- 修复单个停售商品中断整批加购的问题；明确被拒绝的商品不影响其余项，未知结果或登录失效仍停止后续操作。通知提供逐项数量、结果和原因，成功项自动取消勾选。
- 修复收藏缺少购买规则时按错误数量提交的问题；加购前核实起订量和递增量，需要增加数量时先提示确认。
- AD SchLib 的位号和 Comment 默认显示，分行放在符号上方；KiCad Reference / Value 已核验为显示。已有 SchLib 需要重新导出后应用此调整。
- 下载列表移除数量列；列头增加分隔线并支持调整宽度；修正商品区域拖动条的对齐，改善明暗主题和大字体下的布局。

## 性能与诊断

- 收藏数量同步按器件编号直接定位，减少大列表重复遍历。
- 搜索、收藏、购物车和订单图片按可见区域加载并缓存；筛选合并连续请求，复用近期结果，退出时取消后台任务。
- 补齐分类、参数筛选、图片、批量加购和导出过程的诊断信息，记录阶段、耗时与错误，排除登录凭据和订单正文。

697 项全量测试通过，最终便携 EXE 已完成隔离验收与源码一致性核对。AD / KiCad 导出字段使用实际库文件独立读取核验；账号购物流程使用合成数据验证。
