# LCSC3D 2.4.1

- 修复部分器件的数据手册按钮不可用：兼容商城新版 `pdf_property` 资料、厂商链接与旧版 PDF 字段，并在缺失时补用 EDA 目录链接。已核对 C2861386、C507270、C34678、C74511、C69527。
- 商城新增“购物车”“我的订单”，按搜索商品、我的收藏、购物车、我的订单排列；“账号收藏”页签更名为“我的收藏”。
- 搜索和收藏直接填写数量，右键按各行数量加购；支持批量下载、收藏与加购，无中间数量选择页面。
- 原生购物车支持数量自动保存、勾选与移除；原生订单表格支持分页和筛选。“跳转到购物车”直接用外部浏览器打开商城购物车，不提交结算。搜索和购物车显示递增量，数量按步长调整；搜索单价随输入数量匹配，展开可查看全部价格区间。
- 修复批量加购被单个停售商品中断：明确的商品拒绝继续处理后续项，未知结果或登录失效仍停止。通知提供逐项结果并取消成功项勾选；收藏缺失的购买规则在加购前核实，新增规则要求增加数量时先提示确认。退出账号清空原生账号表格；新增数量保存、订单读取、浏览器打开以及批次逐项原因与停止原因诊断。

- 点击订单行后，在订单列表原区域展开商品明细和金额；支持勾选器件加入下载列表、返回保留列表位置。“查看订单详情”移入明细页。
- 购物车增加商品预览图，按可见行后台加载、复用缓存，双击图片可放大。
- 修复 AD SchLib 位号与 Comment 默认隐藏：新导出元件的两项字段默认显示，分行放在符号上方；KiCad Reference / Value 同样核验为显示。
- 搜索页新增原生分类与筛选页面，位于原搜索区域；使用官方分类和筛选接口，支持多选、参数范围、价格/需求数量、排序、现货、数据手册和品牌来源。
- 订单商品增加预览图与原图入口；下载列表移除数量列；列头增加分隔线并可调整宽度，修正商品区拖动条的留白对齐。
- 收藏数量同步按器件编号定位；收藏和订单图片按可见区域加载，复用有界缓存；筛选合并连续请求并缓存近期结果，窗口关闭时取消后台任务。

本地交付版本，不包含推送、标签或 Release 发布。
