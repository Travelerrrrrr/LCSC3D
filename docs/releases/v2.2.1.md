# LCSC3D 2.2.1

新版将工作台、商城、登录和设置整合到一个窗口，启用新的蓝色 L Logo，并加入备份恢复与清理。首次启动默认浅色与品牌蓝，已有个人设置继续沿用。

## 一体化界面与新 Logo

- 顶部直接提供最小化、最大化/还原和关闭按钮，不再显示额外系统标题栏。保留顶部拖动、双击最大化和边角缩放。
- 工作台采用左侧导航、下载列表与四类预览并排、底部导出设置；商城、登录、图片浏览、追加配置、更新、帮助及文件选择都在主窗口内切换。
- 使用 qt-material 2.17，统一按钮、圆角勾选框、下拉列表、分组与提示。提醒从右上角滑入，不遮挡窗口控制按钮。
- 替换应用界面、Windows 窗口和 EXE 的旧图标，关于页字标随浅色/深色切换。

![2.2.1 一体化浅色工作台](../images/2.2.1-release/main.png)

## 备份管理与恢复

- **设置 → 备份** 可开关自动备份，查看备份数量、总占用空间、文件及原路径，打开备份目录。
- 支持恢复 SchLib、PcbLib 和 PCB 工程备份到原位置或指定路径，兼容旧版备份。
- 恢复覆盖前保存当前文件，即使自动备份已关闭；恢复前校验备份内容，并再次确认目标文件未发生变化。
- 清除前展示确认提示，仅删除本次列出的备份。清理后仍可继续创建备份。
- 配置、备份、缓存、日志和更新文件统一保存在 `%LOCALAPPDATA%/LCSC3D/`。

![自动备份、占用空间、恢复与清理](../images/2.2.1-release/backups-light.png)

## 主题、语言与支持

- 简体中文 / English 即时切换，保留队列、导出目录和勾选；English 使用 LCSC 国际商城的英文资料、美元价格、库存与原图。
- 跟随系统 / 浅色 / 深色，默认浅色；预设和自定义配色，默认品牌蓝 `#087AF5`。
- 按钮文字颜色、界面字体及 10–24px 字号可单独调整并保存。字体列表紧凑展开，小窗口及大字号下可滚动。
- 设置分为外观、网络、日志与诊断、关于与支持、备份五类。
- **⭐点个Star⭐** 打开仓库首页；**🍔赞助作者🍔** 在应用内展示支付宝和微信收款码。

![新版外观设置](../images/2.2.1-release/settings-appearance.png)

## 下载与更新

- Windows 10/11 x64：下载 `LCSC3D.exe` 直接运行，无须安装 Python。
- `LCSC3D.zip` 为完整源码包，`SHA256SUMS.txt` 用于验证两个附件。
- 已安装版本可在 **设置 → 关于与支持 → 检查更新** 中下载并重启，启动后台检查也会提示新版。
- 升级后应用内 Logo 和 EXE 图标随程序一起更新；Windows 桌面、资源管理器或固定到任务栏的图标可能需要等待系统图标缓存刷新。已有个人主题设置与导出文件保留。
