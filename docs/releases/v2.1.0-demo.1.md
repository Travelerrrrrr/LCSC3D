# LCSC3D 2.1.0-demo.1 · 商城收藏导入

开发日期：2026-10-08。此版本为本地 Demo，基于 2.0.0 增加官方网页登录与收藏元件导入。

## 使用

打开 `outputs/demo-2.1.0/LCSC3D.exe`，点击 **商城收藏…**，在官方网页完成登录并打开收藏夹。选择 **读取本页** 或 **连续读取**，勾选右侧元件后点击 **加入下载列表**，返回主窗口选择格式并下载。

连续读取从当前页开始。要读取全部收藏，先在商城回到第一页、选择全部收藏并清除筛选；未识别到下一页按钮时可手动翻页后继续读取。界面提供网页缩放、停止、全选/取消、清空读取结果与清除登录。

## 行为

- 登录走商城实际跳转的嘉立创官方登录中心，支持官方网页提供的扫码、账号和手机号入口以及登录弹窗。程序不自行接收密码、复制 Cookie 或持久化登录状态。
- 独立内存会话与模型预览隔离，退出程序释放登录状态。「清除登录」也清除本程序暂存的收藏结果。
- 收藏导入按 C 编号去重，已有勾选、下载结果与预览行不变；新元件默认勾选。下载中禁止向队列导入。
- 只读取收藏页中可见且带有效 C 编号的商品行，排除隐藏行、推荐区、导航与普通页面文本，避免把商品链接的内部数字 ID 当成 C 编号。
- 连续翻页等待商品行稳定后再读取；取消、登录失效、翻页未变化、超时、重复分页及上限均停止继续读取，保留已完成部分。
- 源码及 Windows 版本资源标识 Demo。更新检查允许升级到同版本的正式版，拒绝回退到较旧正式版。

## 验证范围

154 项本地回归全部通过，其中 19 项收藏专项测试覆盖提取、模拟分页、去重合并、下载期间锁定、失效响应过滤、登录弹窗与内存会话清除；其余覆盖模型下载、预览、AD 导出及更新。测试不使用真实账号。

Windows 单文件 EXE 已在独立中文目录下运行，限制 PATH 并清除 Python/Qt 环境变量：

- `--self-test-favorites` 退出码 0。实际冻结程序从本地网页读取两页、三个元件，按勾选导入、跳过重复编号，保留原有取消勾选与「成功」结果；验证内存会话和下载期间导入锁定。
- `--self-test` 退出码 0。C2040/C20197 的 STEP 和 OBJ 实际在线下载成功；3D、符号与封装预览正常，未勾选的 C163691 不下载，无效编号按预期报告失败，窗口句柄保持稳定。

本地原始报告位于 `work/收藏demo便携验证/`，交付文件位于 `outputs/demo-2.1.0/`，附 `SHA256SUMS.txt` 校验和。

在线验证确认内置网页可以跳转并加载 `passport.jlc.com/login`，展示嘉立创官方登录页及扫码/账号/手机号入口。尚未使用真实账号完成登录并验证真实收藏页面；当前页提取和连续翻页仍需用户实号联调。官方页面结构变化可能需要调整 DOM 识别逻辑。

Demo 不发布到正式 Release，也不替换 `outputs/` 根目录的 2.0.0 成品。
