# LCSC3D 2.4.4

本版修复点击下载无反应、取消后文件遗留和进度条不归零的问题，并增加器件数据手册 PDF 批量下载。

## 问题原因与修复方法

- **点击下载无反应**：商城界面延迟初始化时，下载入口提前访问尚未创建的购物车控件，导致下载线程启动前发生异常。此时界面已经被标记为运行中，后续点击也会被拦截。现在未打开商城、未登录账号时都可以直接下载；打开商城后会同步正确的操作状态。启动异常会提示原因、记录诊断并恢复操作按钮，可直接重试。
- **登录后偶尔恢复下载**：旧版打开商城或登录界面会顺带初始化上述控件，因此可能暂时绕过问题；公开模型和元件库下载本身不要求登录。若旧版已经卡住，需先退出重启再操作。
- **取消后遗留文件、结果不准确**：此前仅停止后续任务，已写文件继续保留，部分中断结果又丢失了已写文件记录。现在按整个批次记录文件变更：取消后删除本次新增的模型、PDF 和元件库，恢复本次覆盖、追加及工程关联前的内容，并更新取消结果。原有及无关文件保留；遇到文件占用或外部修改时明确提示，保留恢复资料并记录错误位置。
- **取消后进度条不归零**：此前进度控件只允许向前增长，取消流程也保留当前进度。现在接受取消后从当前显示值以约 320 毫秒的平滑动画退回 0%，等待网络请求和文件清理期间拦截旧进度；再次下载不会被旧动画或迟到信号影响。

## PDF 数据手册批量下载

- 在导出设置勾选 **PDF 数据手册**，下载列表中已勾选器件的手册。默认关闭，可单独下载 PDF，也可与 STEP、OBJ、AD 或 KiCad 元件库一起下载；不依赖器件是否有 3D 模型。
- 文件保存在本次输出目录的 `PDF/`，按 `C编号_型号.pdf` 命名，多份手册加序号分别保存。只使用立创商城明确提供的数据手册链接，包括商城挂出的厂商 PDF 链接；不额外检索其他网站，也不混入认证或 PCN 文件。
- 商城没有手册时在界面提醒，并生成 `PDF/缺少pdf元件型号.txt`，只记录缺失元件的型号和品牌。清单按本批刷新，无缺失时移除旧清单；未勾选 PDF 时不改动清单。
- 网络超时、失效链接、错误网页和不完整 PDF 显示为下载失败，不误记为“无数据手册”。新文件完整下载并验证后才覆盖旧文件；PDF 失败不阻断同批其他格式导出。
- 取消时 PDF 和缺失清单与其他本批输出一起撤销，覆盖前的文件会恢复。

## 升级与补救

- 关闭旧版后，使用本页的 `LCSC3D.exe` 替换并启动；也可通过“设置 → 关于与支持 → 检查更新”升级。重新执行之前没有启动或失败的下载任务。
- 暂时无法升级时，可先重启旧版，打开一次“立创商城”，再返回工作台下载，无需先登录。已经卡住后仅打开商城可能不足以恢复，建议直接升级 2.4.4。
- 如升级后仍出现问题，请提供元件 C 编号、导出格式、复现步骤和“设置”中打包的诊断 ZIP，便于继续定位。
