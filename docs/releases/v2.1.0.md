# LCSC3D 2.1.0

发布日期：2026-10-08。Windows 10/11 x64，单文件便携程序。商城选型和账号收藏已正式整合到 LCSC3D，可直接搜索、查看资料并将所需元件加入下载列表。

## 新增与改进

- **独立立创商城窗口**：搜索和账号收藏使用软件原生界面，点击预览选中元件后主窗口进入前台，商城页面保留。
- **50 条按需分页**：显示总数和页数，点击翻页才获取目标页，跨页勾选保留。元件默认不勾选，查看高亮行与导入选择互相独立。
- **人民币价格梯度与现货库存**：每个商品独立选择真实阶梯，默认 1+ 或最低可购买数量，价格保留原始精度；翻页保留梯度选择。
- **完整商品资料与原图**：修复 EDA 目录缺失商品的详情，长介绍和参数完整换行并可滚动；支持所有商品原图、缩放、平移和切换。
- **账号收藏添加与取消**：获取真实账号收藏、勾选导入，搜索商品可加入账号收藏，已有收藏可单独取消。已导入队列和下载文件保留。
- **三种原生登录**：顶部账号入口支持微信扫码、账号密码、手机验证码及图片验证。记住登录默认开启，以 Windows 当前用户加密保存会话，重启后自动恢复；退出登录清除会话。
- **删除已勾选器件**：同步移除下载列表和输入框中的对应编号，保留其他记录与已下载文件；下载期间禁用删除。
- **README 更新**：增加新版完整操作说明和由正式程序生成的主窗口、商城、原图与登录截图。

继续支持官方 STEP/OBJ 下载、原生 AD SchLib/PcbLib 导出、3D/符号/封装预览及 SHA-256 校验自更新。PcbLib 当前不自动嵌入 3D 模型；需要同时下载 STEP 并在 Altium Designer 中手动关联和核对位置。

## 使用

下载 `LCSC3D.exe` 直接运行，点击「立创商城」搜索，或从账号收藏勾选元件并加入下载列表。选择输出格式与目录后开始下载。旧版用户可使用「检查更新 → 下载并重启」，同版本 Demo 用户也可升级到正式版。

附件固定为 `LCSC3D.exe`、`LCSC3D.zip`（完整可重建源码）和 `SHA256SUMS.txt`。
