# LCSC3D 2.4.0：封装内嵌 3D 模型

2.4.0 默认开启 **封装关联 3D 模型**。批量生成 AD / KiCad 封装库时，软件取得官方 STEP、换算放置基准，并将模型写入封装，减少逐个手动关联模型的操作。

下载 `LCSC3D.exe` 即可在 Windows 10/11 x64 上运行，无须安装 Python 或外部转换工具。

## 3D 模型直接进入封装库

- **Altium Designer**：STEP 内嵌到 `.PcbLib`，模型随库文件保存和搬迁。
- **KiCad 9 / 10**：STEP 内嵌到 `.kicad_mod`，保留 `.pretty` 库结构即可携带模型。
- **KiCad 8**：选择外部模型模式，STEP 位于 `.pretty/LCSC3D.3dshapes/`，使用相对路径；搬迁时保留整个 `.pretty` 文件夹。
- 单器件、合并、保留独立副本及 AD 追加均支持模型关联；**无需另勾 STEP 下载**。
- 模型保持官方 STEP 原始尺寸和内容，不生成缩放副本。修正 Type-C 的水平/高度放置基准以及旧画布原点问题。
- 没有模型或模型关联失败时，保留可用的二维封装并说明原因；不会因为缺少 3D 丢弃整个元件库。

## 新版工作台

![LCSC3D 2.4.0 工作台：三维预览、封装关联模型和消息入口](../images/2.4.0-release/main.png)

- **平滑下载进度**：查询、模型准备、格式处理、合并和写库阶段均推动进度；取消保留实际进度。
- **消息历史**：左侧增加“消息”，可查看已弹出的通知，搜索、筛选、复制和清空记录；重启后可查阅。
- **右上角通知**：新消息在上方出现，早到的消息平滑下移；收起通知不删除历史。
- **轻量模型处理**：仅扫描来源模型的顶点获取放置基准，不构建导出网格、不运行 CAD 内核或比较 STEP/OBJ 表面。
- **代码整理**：应用按界面、服务、EDA 导出、模型及公共模块分包，更新构建、交付与源码检查流程。

## 验证与使用

本版通过 **636 项全量回归测试**、最终 EXE 的进度/消息验收、9 组模型导出自检，以及实际更新助手的替换和重启流程。模型关联覆盖 AD 与 KiCad、合并、独立副本及异常时保留二维结果。详细记录见 [验证记录](../2.4.0验证记录.md)。

勾选 **PcbLib / KiCad 封装库**，保持 **封装关联 3D 模型** 开启，导出后在对应 EDA 中打开。KiCad 库昵称需与导出库名一致。AD / KiCad 普通导出与再次合并覆盖同名库，以本次选择为准；AD 追加保留旧成员，KiCad 暂不支持追加。

商城商品存在不代表官方已经提供符号、封装或模型。单独下载 STEP/OBJ 与库内模型关联分别控制；模型的适用范围与操作见 [使用说明](../../app/README.md) 和 [模型放置说明](../3D模型放置.md)。

Release 附件：`LCSC3D.exe`（便携程序）、`LCSC3D.zip`（完整源码）、`SHA256SUMS.txt`（SHA-256 校验和）。已有版本可从 **设置 → 关于与支持 → 检查更新** 升级。
