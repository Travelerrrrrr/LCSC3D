# LCSC3D 2.1.0-demo.4 · 独立商城窗口、分页与三种登录

开发日期：2026-10-08。基于 2.1.0-demo.3，交付目录为 `outputs/demo-2.1.0-demo.4/`，运行文件 `LCSC3D.exe`，源码包 `LCSC3D.zip`。保留正式版与之前的 Demo，本次仅本地交付。

## 功能与操作

1. **独立商城窗口。** 「立创商城」使用普通独立窗口，可在任务栏切换、移动和最小化。点击「预览选中元件」按高亮行预览，恢复主窗口并置于前台；商城窗口仍打开，当前页和选择保留。
2. **50 条按需分页。** 搜索展示总数、页数和上一页/下一页，每页最多 50 个元件，仅点击翻页时请求目标页。手动勾选跨页保留，导入包含本次搜索所有页的已勾选元件；全选/反选作用于当前页，新搜索清除旧搜索的选择。「单片机」当前返回 1,500 条，对应 30 个软件页。
3. **取消账号收藏。** 「取消收藏」移除当前商品的真实收藏，服务器验证成功后更新列表；已导入下载队列和已下载文件保留。添加收藏仍支持重复操作而不误取消已有收藏。
4. **默认不勾选元件。** 搜索和账号收藏的新行默认不勾选，高亮行、预览与勾选互相独立；返回已经访问的页面仍保留手动选择。
5. **顶部账号入口。** 顶部顺序为版本、账号登录、检查更新、使用说明。主窗口和商城共享登录与退出状态，重启后自动恢复已保存会话。
6. **三种原生登录。** 登录框支持微信扫码、账号密码和手机验证码。密码默认遮蔽；短信发送有 60 秒倒计时，服务端要求的图片验证码在原生登录框完成，支持换图。关闭或取消登录清空输入，取消的旧请求不会重新登录。

保留上一版的商品详情修复、统一商城入口、全部商品原图、缩放与平移。「记住登录」仍默认开启，仅保存 Windows 当前用户 DPAPI 加密的会话，不保存账号密码；退出登录清除会话。服务端会话失效时需要重新登录。

## 验证范围

用户已在原生登录框内完成真实手机验证码登录，包含官方图片验证码。登录成功后的商城账号校验与加密会话保存均通过。账号密码的加密、图片验证、失败与取消流程使用本地模拟服务验证，未使用用户的真实密码。

账号收藏写入验证仅临时添加 C2040，再调用本版取消接口移除；重复添加和重复取消均通过。读取并比较验证前后的收藏集合，原有 13 个收藏完整保留，已保存登录保留。

离线验证覆盖独立原生窗口、Windows 实际前台窗口、50/25 条分页、跨页勾选、默认不勾选、三种登录、图片验证、原图画廊、账号收藏添加与取消，以及加密保存、重建窗口自动恢复和退出清除。真实账号只读验证覆盖保存会话恢复、收藏导入、商品资料、商品原图与搜索前两页。

**212 项完整回归通过，其中 77 项商城专项回归。** Windows 单文件 EXE 在独立中文目录运行，清除 Python/Qt 环境变量，仅保留系统 PATH，三项成品验证均退出码 0 且报告断言通过：
