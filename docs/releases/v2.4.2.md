# LCSC3D 2.4.2

## 商城选型与采购

- 商城提供“搜索商品 / 我的收藏 / 购物车 / 我的订单”四个原生页签。
- 搜索加入官方分类和筛选，支持品牌、封装、参数多选与数值范围、价格、需求数量、排序、现货、数据手册和品牌来源；分类和筛选在原搜索区域内展示。
- 搜索与收藏支持行内数量输入和右键快捷操作，可按各行数量批量加入购物车，也可添加到收藏或下载列表。数量按器件起订量和最小递增量调整，搜索单价随数量匹配，并支持查看全部价格区间。
- 购物车支持商品预览图、数量自动保存、勾选、移除和导入下载列表。“跳转到购物车”使用系统浏览器打开官方购物车，继续确认订单和付款。
- 我的订单支持分页、关键词和状态筛选；点击订单，在原表格区域查看商品图片、器件和物品、数量、单价与金额，并可勾选器件加入下载列表。返回保留列表位置，完整订单入口位于明细页内。

## 修复与界面调整

- 修复部分器件的数据手册缺失，兼容商城新版资料字段、厂商链接和旧版 PDF，缺失时补充官方元件目录资料。
- 修复单个停售商品中断整批加购的问题；明确被拒绝的商品不影响其余项，未知结果或登录失效仍停止后续操作。通知提供逐项数量、结果和原因，成功项自动取消勾选。
- 修复收藏缺少购买规则时按错误数量提交的问题；加购前核实起订量和递增量，需要增加数量时先提示确认。
- AD SchLib 的位号和 Comment 默认显示，分行放在符号上方；KiCad Reference / Value 已核验为显示。已有 SchLib 需要重新导出后应用此调整。
- 下载列表移除数量列；列头增加分隔线并支持调整宽度；修正商品区域拖动条的对齐，改善明暗主题和大字体下的布局。

## 性能与诊断

- 收藏数量同步按器件编号直接定位，减少大列表重复遍历。
- 搜索、收藏、购物车和订单图片按可见区域加载并缓存；筛选合并连续请求，复用近期结果，退出时取消后台任务。
- 补齐分类、参数筛选、图片、批量加购和导出过程的诊断信息，记录阶段、耗时与错误，排除登录凭据和订单正文。

以上保留 2.4.1 的更新内容；2.4.1 已通过 697 项测试。

## 2.4.2 范围筛选修复

- 修复 MCU 程序存储容量输入 `32KB–64KB` 后点击“选用范围”，数值和单位被清空或重置的问题。所选范围在异步刷新、分组切换和重新打开筛选时保持一致。
- 范围内的选项按商城基准单位进行数值匹配，包含边界、单边范围和零值；支持与当前项文字搜索组合使用。商城返回完整选项时，界面仍正确显示范围内的匹配项。
- 保留刷新期间尚未提交的输入，以及服务端暂未返回的已选参数分组；清除、重置或改选离散项后同步更新范围状态。“应用筛选”也会校验并采用当前填写的有效范围。
- 补充范围选择和非法输入的诊断事件，记录边界是否填写及匹配数量，不记录搜索词、具体输入或账号资料。

## 2.4.2 性能优化

- 恢复并适配 main 分支 `f772bad` 的优化，保留 2.4.1 的商城、购物车和订单功能。
- 同批导出复用模型下载、校验及压缩结果，并发请求共享同一结果；缓存限制容量，批次结束释放，失败或取消后可重试。
- 3D 预览使用紧凑的顶点存储和二进制传输，减少重复序列化；显示完成后释放传输数据，降低大模型预览的内存占用。
- 商城复用 HTTP 连接，保持账号 Cookie 隔离和原有错误诊断；写入请求不自动重放。
- 图片在线程中解码，原图缓存按解码后的内存大小限制；大列表图标有数量上限，继续按可见区域加载。
- 延迟创建商城表格，后台读取备份列表；增量更新消息列表和批量进度，减少启动与操作时的主线程工作。移除未使用的 Qt PDF 打包组件。

## 2.4.2 验证

发布流程要求 Windows 全量回归、日志诊断与故障注入测试通过，并对最终便携 EXE 完成隔离验收。验收覆盖范围筛选刷新、商城与采购、设置及日志导出/清除、备份、AD / KiCad 导出、模型与预览、进度消息、启动及自更新；同时核对 EXE 内模块、资源、源码 ZIP 和校验和。账号购物流程使用合成数据，在线检查仅访问公开器件与模型。
