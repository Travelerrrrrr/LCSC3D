# LCSC3D 2.1.3 本地交付

日期：2026-10-10。此版仅在本地构建和提交，未推送、打标签或发布 Release。

- AD 元件库后新增 Lib 合并、追加互斥勾选框，按模式显示配置；移除“库与工程…”入口。
- “同时单独输出”统一改为“独立导出器件”，追加与只指定 PCB 工程的流程均支持。
- 未独立导出时，3D 文件集中到 SchLib 旁的同名文件夹；仅有 PcbLib 时跟随其名称。库文件保留原位置。
- 追加支持只选 SchLib 或 PcbLib，主页保存目录持续禁用。选定已有库和工程后可同时追加并将库加入工程；未勾选联动时工程保持原样。
- 只指定工程时，按工程名称创建或继续追加配套库。空下载列表可直接把所选已有库加入工程，重复引用跳过。
- 补充配置、导出路径策略、库提交、工程导入和失败诊断日志，继续使用 AppData 备份与临时目录。

验证范围及实测结果见 [验证记录](../验证记录.md)。
