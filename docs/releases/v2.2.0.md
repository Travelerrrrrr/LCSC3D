# LCSC3D 2.2.0 本地交付

日期：2026-10-10。版本号按用户要求统一为 2.2.0。仅本地构建和提交，未推送、打标签或发布 Release。

- 修复 SchLib 导出中 `NONE` 无填充被当作颜色的问题，覆盖矩形、圆/椭圆、多边形和路径等图元；保留非法颜色校验。
- 合并、追加和工程模式中集中保存的 STEP/OBJ 文件夹统一为 **库名_3D**，优先跟随 SchLib，仅有 PcbLib 时跟随 PcbLib。旧目录和文件保留。
- 合并和追加 PcbLib 时排除随机标识及供应商元数据差异，核对实际封装内容后复用相同 footprint。SchLib 模型引用及 Footprint 参数、独立输出的配套库同步使用保留名称。
- 同名但焊盘、图元或其他有效数据不同的封装使用序号区分；原有库内容、名称和历史重复项保持原样，不再新增等价条目。
- Lib 文件及新库内名称不自动附加器件编号；独立导出的父文件夹继续保留“型号_C编号”。
- 保留 Lib 合并/追加互斥模式、独立导出、单库追加、PCB 工程联动、空列表直接导入和自动备份，并补充封装复用及独立输出诊断日志。

实测使用 C23922 / STM32F030C8T6 与 C8734 / STM32F103C8T6：两个符号共用一份 LQFP-48 封装。完整测试结果见 [验证记录](../验证记录.md)。
