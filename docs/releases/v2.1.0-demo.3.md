# LCSC3D 2.1.0-demo.3 · 完整商城搜索与商品资料

开发日期：2026-10-08。本地 Demo 基于 2.1.0-demo.2，交付目录为 `outputs/demo-2.1.0-demo.3/`，保留前一版 Demo 和正式 2.0.0，不发布为正式 Release。

## 本次修改

1. **修复商品详情缺失。** C20618009 没有出现在之前使用的 EDA 目录中；收藏行又缺少图片和封装，所以右侧显示空白。本版使用商品的商城编号获取正式商品页的结构化资料，EDA 目录只补充符号、封装和 3D 资源。此商品现在显示型号 `OD1EL89CEIBXE6YLC-100M`、封装 `SMD5032-6P`、7 项参数和 4 张图片。
2. **统一商城入口。** 主窗口的「搜索商品」和「商城收藏」合并为「立创商城」，内部保留搜索和账号收藏两个页签，重复打开保留原来的页签与选择。
3. **预览保留商城窗口。** 「预览选中元件」更新主窗口预览，商城窗口、当前行和勾选保持。
4. **搜索商品收藏到账号。** 选中商品点击「收藏到账号」，使用已登录的真实商城账号保存，并更新账号收藏列表。官方添加接口会切换收藏状态，因此先查询状态，只对未收藏商品调用一次添加，随后验证结果；已有收藏不会被重复添加操作取消。
5. **全部商品原图和放大。** 点击商品图片或「查看全部原图」，打开原生图片窗口，支持缩略图、上一张/下一张、方向键、滚轮及按钮缩放、原始像素显示、拖动平移与适应窗口。使用官网原图路径，C5879483 的三张原图均保留；详情尚未加载完成时点击图片，会等待完整图库后自动打开。
6. **完整搜索结果。** 原 EDA 搜索固定返回前 50 条且忽略分页参数；本版使用商城 `/query/product` 和它支持的 30 条页大小，逐页获取全部结果，显示数量与进度。停止或失败保留已获取的部分，重复分页与异常分页明确报错。搜索完成后按精确编号或型号排序，保留读取过程中用户的勾选和当前行。2026-10-08 实测「单片机」为 1,500 条、50 页，全部成功读取。

扫码登录与 Windows 当前用户 DPAPI 加密保存继续保留。退出登录清除保存的登录状态；关闭商城或图片窗口不退出账号。搜索结果和收藏元件均可去重加入下载列表，保留已有下载结果和选择。
