# LCSC3D 2.1.1

发布日期：2026-10-09。Windows 10/11 x64，单文件便携程序。

## 新增与改进

- **启动后台检查更新**：主窗口显示后自动检查一次，发现新版弹出可下载的更新窗口；已是最新版、连接失败或接口异常均保持静默，失败写入日志。手动检查继续显示结果，转为手动检查或关闭软件后不会补弹启动提醒；网络等待不会延迟关闭软件。
- **设置窗口**：主窗口顶部增加“设置”，代理和日志选项集中管理，支持保存和取消。
- **独立代理选项**：立创商城和检查更新分别选择“使用系统代理”或“不使用系统代理”，默认均使用系统代理。商城选项覆盖登录、搜索、收藏、图片及元件资源；更新选项覆盖新版检查、校验文件和程序下载。
- **即时生效与配置记忆**：保存后用于后续请求，现有登录会话保留。配置与原有下载目录、格式选项一起保存，重启和自更新后恢复，兼容 2.1.0 的配置文件。
- **集中存放程序数据**：配置、日志、会话、缓存、临时文件、运行时解压和更新暂存/备份统一位于 `%LOCALAPPDATA%/LCSC3D/`。不在 EXE 旁生成配置文件，旧配置成功迁移后清除；模型和库默认保存到该目录下的 `downloads/`，仍支持主动选择导出目录。
- **日志等级**：支持 Debug、Info、Warning、Error、Critical，默认 Debug；“打开日志”可打开日志目录。日志记录版本、步骤、代理模式、耗时、数据大小和异常位置，并限制文件大小及备份数量。
- **打包与清除日志**：“打包日志”收集主程序、更新助手、轮转、崩溃日志和运行状态标记，并附软件/系统环境、当前代理与日志选项、反馈说明。ZIP 在 AppData 的 `diagnostics/` 内生成，完成后打开目录。“清除日志”经确认后清除日志并继续记录，保留已打包的 ZIP、设置、会话和下载文件；占用或权限失败会提示。
- **本地更新测试入口**：无需发布 GitHub，即可通过本机模拟服务完整验证检查更新、下载、SHA-256 校验、替换及重启。启动脚本自动使用隔离副本，支持成功、校验失败、没有新版及自动点击验证。测试源只对显式启动参数生效，不保存到正式设置。详见 [本地更新测试](../本地更新测试.md)。
- **功能日志与故障定位**：覆盖商城、登录、图片、收藏、队列、下载、AD 转换、文件写入、三类预览、配置/会话及自更新全过程。记录根操作/子步骤编号、元件与格式、错误码、异常原因链和代码位置；线程池和独立更新助手延续关联。增加 Python/线程未捕获异常、渲染进程退出及可捕获崩溃的线程栈。详见 [日志覆盖与排查](../日志排查.md)。
- **登录错误排查**：修复 HTTP 响应中断、压缩数据损坏及异常二维码/授权数据导致的笼统失败提示。错误现在显示具体步骤和原因，日志不含密码、Cookie、验证码、授权链接或异常原文。
- **登录前置校验**：前置校验失败时停止提交密码或发送短信，正常图片验证流程保留。

选择“不使用系统代理”会同时忽略环境变量代理；浏览器网页和 VPN/TUN 等网络层转发由相应软件控制。

## 验证

321 项本地回归通过，包含 7 项启动后台检查回归、12 项本地更新源与窗口回归；其中 15 项新增日志打包/清除与窗口交互验证、23 项专项故障注入核对日志可定位到具体功能、元件/格式/阶段、原因链和代码位置。代理回归通过本地 HTTP 服务核对实际直连/代理路由、两个选项独立生效、已有客户端即时切换及 Cookie 保留。窗口回归核对默认值、保存、取消、写入失败和日志目录打开目标；日志回归核对等级过滤、敏感数据排除及文件轮转。文件路径回归核对旧配置迁移、迁移失败保留、AppData 内部文件、下载临时文件和跨盘替换；真实 EXE 普通启动/关闭验证目录清洁。

完整测试数量、冻结程序的设置与商城验证，以及便携运行和自更新结果见 [本地验证记录](../验证记录.md)。登录验证使用受控本地服务；本版不发送真实短信或提交真实账号登录。
