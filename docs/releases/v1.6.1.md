# LCSC3D 1.6.1

Windows 10/11 x64 便携版，直接运行 `LCSC3D.exe`，无需安装 Python 或额外浏览器运行时。

- 修复载入列表后“型号 / 模型”列为空的问题，后台自动查询全部元件的型号及关联模型名，无须先开始下载。
- 未勾选的元件同样显示型号；查询失败时提供错误提示，可重新载入重试。
- 下载列表支持勾选、全选和反选，仅下载勾选的元件，重新载入按编号保留勾选状态。
- 支持 STEP、WRL、OBJ 下载，以及官方 3D、符号和封装预览。
- 整理开源目录、许可证、贡献说明和 Windows 自动测试与构建。

64 项本地测试通过；实际 EXE 在独立中文目录完成联网验证，下载前型号显示、勾选过滤、三个模型格式和预览切换通过。

下载附件：

- `LCSC3D.exe`：Windows x64 独立单文件程序。
- `LCSC3D.zip`：完整源码及固定版本上游源码，包含构建脚本、测试和许可证。
- `SHA256SUMS.txt`：上述两个文件的 SHA-256 校验和。

源码采用 AGPL-3.0-or-later，第三方软件依照各自许可证。模型和器件数据来自 [JLCEDA 官方库](https://lceda.cn/) / [EasyEDA 官方库](https://easyeda.com/)，数据的版权和使用条件由官方库决定。
