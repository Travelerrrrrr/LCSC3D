# LCSC3D 2.4.3

本版优化界面响应、表格阅读与分类浏览，修复采购和筛选状态恢复问题，并加强异常诊断。

- 下载列表的“结果”列自动填充到表格右侧，调整窗口、分栏或出现滚动条时保持对齐。
- 商城分类的二级菜单默认收起，点击箭头按需展开；查找分类仍可直接找到下级分类。
- 搜索、收藏、购物车和订单商品明细统一显示多行商品简介。型号加粗，品牌、封装、类别、简介与已有关键参数分层展示；长文字适当省略，悬停可阅读完整内容。商城未提供简介时明确显示占位提示。
- 商品行高度随字体调整，数量和价格控件保持正常高度并垂直居中；浅色、深色及英文界面同步适配。
- 修复备份表格最右侧“大小”列的反向调宽感：拖动该列时保持前面的路径列宽度，超出区域可水平滚动。
- 搜索和订单使用数字页码、省略号与前后箭头，当前页以描边突出，支持直接跳页；跨页勾选保留，加载期间禁用翻页，窄窗口自动精简页码。
- 默认跟随系统界面字体，改善文字平滑度；修正控件边框、下拉选中状态与分类树绘制，保留明暗主题和字号设置。
- 购物车批量勾选只计算一次合计，商品简介复用有容量上限的排版结果；启动命中主题缓存时按需加载样式生成器，减少重复工作。
- 刷新购物车前保存尚在等待提交的数量，避免刚输入的数量被旧数据覆盖；保留失败后核对和重试流程。
- 取消分类刷新后可以重新刷新；收藏筛选恢复当前行时同步恢复商品详情。关闭右键菜单后释放控件，避免长期操作积累菜单和动作。
- 修复商品简介含 emoji 等补充平面字符时，换行后的文字可能被跳过的问题。
- 英文设置菜单使用完整的 “About and support” 文案，避免连接符被识别为快捷键标记。
- AD 封装关联 3D 支持选择 Mechanical 1–32；独立导出、合并和追加的新封装均使用所选机械层。
- 加强文件名、数值、压缩网络响应、配置与消息恢复、备份清理、批次异常和旧更新记录的错误处理；保留已成功输出的文件和诊断信息。
- 日志目录无法读取时仍可打包环境诊断，并在报告中标明缺失原因；恢复访问后可继续收集日志。

分页操作记录页码、来源与总页数；待保存数量的刷新处理及日志目录读取失败新增诊断事件。日志不记录商品介绍、搜索词、订单正文或登录凭据。
