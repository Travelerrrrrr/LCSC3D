# LCSC3D 2.4.3

本版围绕表格阅读、分类浏览与翻页操作改善使用体验。

- 下载列表的“结果”列自动填充到表格右侧，调整窗口、分栏或出现滚动条时保持对齐。
- 商城分类的二级菜单默认收起，点击箭头按需展开；查找分类仍可直接找到下级分类。
- 搜索、收藏、购物车和订单商品明细统一显示多行商品简介。型号加粗，品牌、封装、类别、简介与已有关键参数分层展示；长文字适当省略，悬停可阅读完整内容。商城未提供简介时明确显示占位提示。
- 商品行高度随字体调整，数量和价格控件保持正常高度并垂直居中；浅色、深色及英文界面同步适配。
- 修复备份表格最右侧“大小”列的反向调宽感：拖动该列时保持前面的路径列宽度，超出区域可水平滚动。
- 搜索和订单使用数字页码、省略号与前后箭头，当前页以描边突出，支持直接跳页；跨页勾选保留，加载期间禁用翻页，窄窗口自动精简页码。

分页操作记录页码、来源与总页数，沿用已有请求失败、界面回调和崩溃诊断；日志不记录商品介绍、搜索词、订单正文或登录凭据。
