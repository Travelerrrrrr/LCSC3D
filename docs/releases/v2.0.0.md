# LCSC3D 2.0.0

输入立创商城 C 编号，批量下载官方 STEP/OBJ 模型，导出 Altium Designer 原生 SchLib/PcbLib，并在软件内预览 3D、符号和封装。

## 主要功能与变化

- 新增原生 AD 符号库与 PCB 封装库导出，无须安装 AD 即可生成。支持多单元符号、真实引脚编号、电气类型，以及常见和自定义焊盘、钻孔、槽孔、铜孔偏移、阻焊/锡膏扩展。遇到暂不支持的图元时明确提示失败，其他成功资源保留。
- 修复符号轮廓比例、原理图库画布与引脚文字样式、多单元归属、自定义焊盘及铜区关联等问题。AD 导出回归包含 27 个官方样本，并用独立读取器核对实际库记录。
- AD 库文件仅按元件型号命名，例如 `RP2040.SchLib`、`RP2040.PcbLib`；文件夹仍为“元件型号_C编号”。STEP/OBJ 文件名保持原规则。
- 下载固定重新获取所选资源并覆盖已有同名文件，取消覆盖开关。成功后原子替换，失败、取消或文件被占用时保留原文件，未选格式不替换。
- 本地 WebGL 预览官方 OBJ，初始视角及“适应窗口”保持元件顶部朝上；支持旋转、缩放和平移。符号/封装预览保留官方 SVG 图形，多单元符号可选择单元。
- 新增“检查更新”与便携程序自更新：后台下载、SHA-256 校验、替换和重启，保留设置；替换或启动失败时恢复原程序。
- 保留批量输入、后台型号查询、勾选下载、全选/反选、停止、镜像回退、连接复用和受控并发。任务结果按本次勾选器件统计，下载期间预览可继续操作。
- README 更新详细功能与使用方法，补充软件、商城对照及 AD 实机截图。

## 下载与使用

Windows 10/11 x64，下载 `LCSC3D.exe` 后直接运行，无须安装 Python。每个器件独立保存所选的 STEP、OBJ、SchLib、PcbLib，不导出 JSON、SVG 或 CSV。

PcbLib 当前不自动内嵌或绑定 STEP，也不生成 IntLib。需要在 AD 中显示三维封装时，请自行将下载的 STEP 添加为 3D Body 并调整位置。没有关联 3D 模型的元件仍可导出可用的二维库。

1.x 用户首次升级到 2.0.0 请手动下载 EXE，后续正式版本可使用程序内自更新。自更新需要程序目录可写。

## 验证

134 项本地回归测试通过，包含 27 个官方 AD 样本；实际便携 EXE 已验证 STEP/OBJ 下载、三类预览、窗口稳定性，以及 C2040、C20197、C2765186 连续两次 AD 导出与覆盖。具体验证范围见仓库中的 `docs/验证记录.md`。

## 发行附件
