# 立创 3D 模型下载器

Windows x64 便携软件，支持 3D 模型下载和 Altium Designer 原生符号、封装库导出。运行 EXE 即可使用，无须安装 Python、KiCad、AD、浏览器插件或额外浏览器运行时。

当前版本：1.1.0。新增 AD 符号（SchLib）与 AD 封装（PcbLib）导出，可用 STEP 自动嵌入封装库。左右栏间距为 24 个逻辑像素，分隔条可拖动。

## 使用

1. 输入立创 C 编号，可以使用换行、空格、中英文逗号和分号分隔。编号不区分大小写，重复编号会自动合并。
2. 选择保存目录和导出内容。默认下载 STEP；可选 WRL、OBJ、“AD 符号”、“AD 封装”。只需要 AD 库时可取消全部 3D 格式。
3. 点击“开始下载 / 导出”。每个器件保存到独立的 C 编号目录，结果写入 UTF-8 CSV 下载报告。
4. 选中列表中的器件，点击“在线预览”，或双击器件。鼠标拖动旋转，滚轮缩放。

预览可以在下载前使用：先“载入列表”，再选中器件。预览采用立创商城正在使用的官方在线查看器，由查看器按 C 编号联网获取模型。软件没有实现自有的 3D 模型解析器或渲染器；WRL 导出使用上游转换功能。

示例输入：

```text
C2040
C20197, C163691
```

保存结构示例：

```text
所选目录/
  C2040/
    C2040_LQFN-56_L7.0-W7.0-P0.4-EP.step
    C2040.SchLib
    C2040.PcbLib
    model-info.json
  C20197/
    ...
  下载结果_年月日_时分秒.csv
```

STEP 原样保存，适用于 FreeCAD、SolidWorks 等 CAD 软件；WRL 适用于 KiCad；OBJ 为官方模型文本。SchLib/PcbLib 是 AD 原生库文件，保存在同一个器件目录中；符号关联封装名称和对应 PcbLib。AD 封装导出会自动尝试获取并嵌入 STEP，无须勾选独立 STEP 下载。

在 Altium Designer 中通过 File → Open 打开 SchLib/PcbLib，或在 Components 面板的库设置中安装这两个库。首次使用请检查引脚编号、焊盘尺寸、层映射与 3D 方向；AD 26 是本项目的目标使用版本，文件结构回读验证不能替代 AD 内的实际检查。

默认保留已有的非空文件，勾选“覆盖已有文件”可更新文件。零字节文件会重新生成。各格式独立处理：没有 3D 模型的器件仍能导出符号和二维封装；STEP 不可用时封装继续保存，结果注明未嵌入模型。某个格式失败时，其他已经保存的文件会保留。原始来源和转换器版本记录在 model-info.json。

保存目录与可选格式记录在 EXE 同目录的 `LCSC3D-settings.json`；目录不可写时不会保存设置。浏览器在临时目录运行，关闭后释放，不需要安装 WebView2。

下载和预览需要网络及官方服务器可用，预览还需要能运行 WebGL 的显卡驱动。部分器件没有符号、封装或 3D 数据，软件会显示对应结果。停止时网络请求在当前读取结束后响应（连接读取超时为 18 秒），正在运行的 AD 转换进程会终止；完整文件会保留。

## 源码与构建

对应源码包含 GUI、下载适配器、官方查看器接入页面、离线 AD 后端、测试、打包脚本及上游源码。自有代码采用 AGPL-3.0-or-later，easyeda2kicad 采用 AGPL-3.0，EasyKiConverter 转换核心采用 GPL-3.0；原始核心源码与固定提交清单位于 native/vendor/EasyKiConverter。

本版本使用 Python 3.12.10、PySide6 6.11.1、PyInstaller 6.20.0 构建，目标系统为 Windows 10/11 x64。AD 后端使用 MinGW GCC 15.2、Qt 6.10.1 Core/Gui，其私有 DLL 位于 native/runtime，独立进程运行。
打包配置会排除构建环境中可能来自 Poppler/Conda 的同名 ICU DLL，使用 Qt 所需的 Windows 自带 ICU API；Chromium 的 ICU 数据资源仍包含在 EXE 中。

在 Windows x64 安装 Python 3.12、CMake、Ninja、MinGW 工具链和与其匹配的 Qt 6 Core/Gui 开发包，进入源码目录运行（路径按本机安装位置替换）：

```powershell
.\build.ps1 -QtPrefix C:/Qt/6.10.1/mingw_64 -CompilerPrefix C:/Qt/Tools/mingw/bin
```

构建结果位于 `dist\LCSC3D-Portable-v1.1.0.exe`。依赖安装需要网络，运行成品不需要 Python 或 AD。也可以安装 requirements.txt，运行 native/build_native.py 构建转换后端，再执行 python main.py。后端未构建时仍可进行 3D 下载和在线预览，AD 导出会显示明确的构建提示。

本地测试：`python -m unittest discover -s tests -v`。
联网成品验证：`LCSC3D-Portable-v1.1.0.exe --self-test .\verification`（将请求三个测试编号，保存模型、AD 库、报告、界面图与 verification.json，验证结束后自动关闭）。构建流程要求原生后端测试通过；单独运行测试时未构建后端会跳过原生测试。
