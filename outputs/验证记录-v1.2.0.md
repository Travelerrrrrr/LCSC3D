# 1.2.0 符号与封装预览验证

验证日期：2026-10-06。环境：Windows x64、Python 3.12.10、PySide6 6.11.1。

- 右侧预览区域上方新增“3D 模型 / 符号 / 封装”切换按钮。符号和封装无需先下载或导出，后台获取官方器件数据；切换二维预览类型复用缓存，切换器件后自动更新，重新加载重新查询。
- 二维预览复用固定版本 easyeda2kicad 1.0.1 的 SVG 渲染功能，使用 QtSvg 显示。支持滚轮缩放、拖动平移、适应窗口、多单元符号选择和封装图层颜色说明。焊盘编号按焊盘尺寸调整字体，防止细间距编号重叠。
- 40 项本地测试全部通过，覆盖真实符号引脚线与封装编号/位置、缺少一种库时另一种预览仍可用、多单元符号、空图形、缓存、快速切换后旧请求丢弃、失败重试、缩放平移与适应窗口、关闭取消请求，以及原有下载、AD 导出和首次预览窗口稳定性检查。
- 使用真实 C2040、C20197 数据检查了默认 1240×850 和最小 1060×787（逻辑像素，Windows 150% 缩放）界面。主窗口及预览控件均正常显示，焊盘编号可读。
- 源码与实际 v1.2.0 EXE 的联网验证均通过。成品在独立中文目录中运行，清除 Python/Qt 相关环境变量，PATH 仅保留 Windows 系统目录；退出码为 0。
- 实际 EXE 显示 C2040 的 57 个符号引脚与封装焊盘，以及 C20197 的 8 个符号引脚与封装焊盘；两个器件分别完成符号/封装切换并保存截图，预览错误列表为空。
- 官方 C2040 3D 在线预览状态为 ready。preview_window.hwnd_preserved 为 true，preview_window.events 为空，三种预览切换期间未隐藏或重建主窗口。
- 两个器件均成功生成 STEP、WRL、OBJ、SchLib、PcbLib，封装嵌入 STEP；无效 C999999999999 正确失败。器件目录仍为“器件名_编号”，递归检查没有 CSV 文件。
- 原生 AD 后端清单校验通过，本轮没有修改转换核心。二维预览展示官方库原始图形，AD 内的验证范围见 验证记录-v1.1.0.md。
- 源码包包含当前预览实现、测试、上游 SVG 渲染源码与构建所需文件，排除了 CSV、编译运行目录、缓存与日志。
