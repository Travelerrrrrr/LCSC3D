# 1.1.1 首次在线预览闪动修复验证

验证日期：2026-10-06。环境：Windows x64、Python 3.12.10、PySide6 6.11.1。

- 复现旧版问题：首次创建浏览器渲染控件时，Qt 对主窗口发出 Hide、SurfaceAboutToBeDestroyed、WinIdChange，再重新创建并显示窗口；主窗口句柄发生变化。
- 修复：在主窗口首次显示前创建预览控件，并加载不含远程资源的本地空白页，初始化 Qt 渲染控件。启动界面继续显示原提示占位页，点击预览后才加载商城查看器与器件模型。仅提前创建 QWebEngineView 而不加载本地页面仍会复现问题。
- 25 项本地测试全部通过。新增两项实际 Windows 窗口回归测试，覆盖显示窗口后立即首次点击、最大化窗口双击预览、切换器件及重新加载；验证 WebGL 可用、窗口句柄、可见状态、大小位置和最大化状态保持稳定。
- v1.1.1 便携 EXE 从独立中文目录运行，清除 Python/Qt 相关环境变量，PATH 仅保留 Windows 系统目录；退出码为 0。
- 实际 EXE 的官方 C2040 预览状态为 ready，preview_window.hwnd_preserved 为 true，preview_window.events 为空：首次预览至验证结束未隐藏或重建主窗口。
- C2040、C20197 均成功生成 STEP、WRL、OBJ、SchLib、PcbLib，封装嵌入 STEP；无效 C999999999999 正确失败，批次继续完成并生成报告。
- 原生 AD 后端清单校验通过；本轮未修改转换核心和 AD 导出逻辑。AD 文件验证范围见 验证记录-v1.1.0.md。
